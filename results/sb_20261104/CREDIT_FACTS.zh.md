# DAPO-SB 训练中 advantage 的实际分配（离线复算，2026-11-05）

- 来源：训练 rollout 账本 `data/rollouts.jsonl`，其中每条轨迹有每个 assistant 回合之前的探针值 b、对错、裁图数、生成 token；以及更新账本 `data/updates.jsonl`，记录每步保留的题号。
- 脚本：`data/credit_facts.py`，输出 `data/credit_facts.json`。
- 公式与训练代码相同（λ=1）：$A_{i,k}=(Y_i-b_{i,k})/(\sigma_q+10^{-6})$，$\sigma_q$ 为组内 Y 的样本标准差（ddof=1）。
- 同一批组上按 DAPO 公式算的对照：$A_i=(Y_i-\bar Y_q)/(\sigma_q+10^{-6})$。
- 每回合的 token 数不在账本里；"按 token 加权"一栏用"生成 token / 回合数"近似。
