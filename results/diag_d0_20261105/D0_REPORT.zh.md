# D0 组内对比诊断（2026-11-05）

问题：在真正产生梯度的组（混合组，8 条里 1–7 条答对）里，对与错的差别落在哪里？是取证（裁到 / 没裁到证据）、取证之后（看到了但用错），还是与证据无关？

- 只用 CPU；读取已有训练账本、rl4k 的 L0 / L1 / L2 标注和 E1 轨迹。
- 脚本 `d0_within_group.py`，输出 `d0.json`。
- 只列事实，原因留给用户推导。

## 名词（同见记忆 icml-glossary）
- **rl4k**：RL 训练题池，4,096 题，原图互不重复。
- **L0**：每题的定性标签，包括可答性、GT 核对、任务标签。
- **L1**：证据框（3,559 题）。
- **L2**：框中读值、绑定关系和充分证据组合 evidence_sets（3,255 题）。
- **LC**：没有常规框的题的线索层（681 题）。
- **E1**：评测集，552 题 × 4 次采样。**E1 与 rl4k 没有交集**，E1 上只有 V\* 有官方框。

## 口径
- 证据状态 EV：L2 的某个充分证据组合里，所有框都在某个已呈现视图（含原图）中达到可用尺度。取训练账本字段 `phi==1`（reward_sg 计算）。**尺度阈值未校准**：文字 6→14 px，物体 16→48 px。
- 原图已足够（orig_sufficient）：只看原图就满足 EV（`phi0==1`），与策略无关。
- 纯几何口径 GEO：第一组证据框都被某一张裁图覆盖 ≥90%，不看尺度，也不计原图。
- 只统计可判题 m=1：可答、GT 一致、有完整的证据组合。
- 配对：混合组内每一对（答对 i，答错 j）。
- 数据来源：
  - DAPO-SB 训练账本（DAPO 的过滤与补采；第 1–2 次更新的 rollout 就是 A-SFT 起点策略）；
  - GRPO+A 训练账本（GRPO 采样，奖励含 S）。
  - 纯 GRPO / DAPO 的账本里没有裁图框，所以组内取证分析用这两份代替；L0 构成用的是纯 GRPO / DAPO 的账本。

## F1 进入梯度的混合组里，约 23% 来自无法由图像判对的题（group / 数据层）

| | 题池 4,096 | GRPO 混合组 2,309 | DAPO 实际更新组 4,095 |
|---|---:|---:|---:|
| 可答且 GT 一致 | 80.9% | 78.4% | 77.3% |
| L0 判为不可答 | 14.3% | 17.3% | **18.0%** |
| GT 与图不符（disagree） | 3.5% | 3.1% | 3.4% |
| GT 无法判断（cannot_tell） | 1.3% | 1.3% | 1.3% |

- 不可答的原因：needs_temporal 406 题（单张图回答不了时间类问题）、ambiguous 38、外部知识 36、找不到证据 31、分辨率不够 26。
- 这些组的平均答对条数：不可答 3.30，GT 不一致 2.97，GT 无法判断 3.27；可答组是 4.33（DAPO 账本）。
- DAPO 只按组内方差过滤，这类题更容易成为混合组：在题池里占 19.1%，在更新组里占 22.7%。

## F2 组内对错的差别，大部分不落在取证上

可判题的混合组配对（DAPO-SB 账本，32 次更新共 34,066 对）：

| 配对类型 | 尺度门口径 | 纯几何口径（只看裁图） |
|---|---:|---:|
| 原图已足够（两条都看得见证据） | **34.2%** | — |
| 答对的取到证据、答错的没取到（取证差异） | 14.8% | 23.6% |
| 两条都取到证据，一对一错（取证之后） | 11.4% | 22.2% |
| 两条都没取到证据 | 34.7% | 44.3% |
| 答错的取到、答对的没取到（反向） | 5.0% | 9.9% |

- 起点（第 1–2 次更新，A-SFT 策略）到后期（第 25–32 次）：取证差异 13.7% → 14.4%；取证之后 4.4% → 15.1%（几何口径 6.2% → 33.4%）。GRPO+A 账本的方向相同：取证之后 5.2% → 27.4%。
- 分来源（后期，尺度口径）：mme 的取证差异 19.6%；worldbench 只有 4.8%，原图已足够 52.3%。
- 分任务标签（后期）：table 的取证差异最高（23.3%）；instance 和 relation 以原图已足够为主（69% / 55%）；chart 以两条都没取到为主（64%）。

**E1 V\***（官方框，同题 4 次采样作组，几何口径）：

| | 取证差异 | 取证之后 | 都没覆盖 | 反向 | 覆盖率 | P(对\|覆盖) | P(对\|未覆盖) |
|---|---:|---:|---:|---:|---:|---:|---:|
| A-SFT | **45%** | 15% | 37% | 3% | .58 | .94 | .63 |
| GRPO | 29% | **51%** | 14% | 7% | .84 | .90 | .56 |
| DAPO | 22% | **53%** | 21% | 4% | .86 | .92 | .58 |
| DTPO | 14% | **74%** | 4% | 8% | .89 | .90 | .56 |

每个方法的配对数是 99–150，样本小。

## F3 组内能区分对错的信号都很弱
可判题的混合组内，以“答对的分数高于答错”计的 AUC（DAPO-SB 账本，全程）：

| 信号 | AUC |
|---|---:|
| 停止探针 b_last | .611 |
| b_max | .603 |
| 证据尺度 phi | .571 |
| 几何覆盖 | .569 |
| gate | .532 |
| 裁图数 | .498 |
| 生成 token | .479 |

- 可判题中，排除原图已足够的题后：P(对 | 取到证据) .71，P(对 | 没取到) .49。

## F4 DAPO 丢掉的全错组，多数已经取到过证据
- 可判题的全错组（356 组）中，75.6% 至少有一条取到了完整证据；49.7% 只看原图就已足够。
- 至少有一条最终探针 b ≥ .5 的组占 15.4%。

## F5 其他
- **k=1 组里唯一答对的那条**：取到证据的比例 .635，k≥4 组的答对轨迹 .644，两者无差别；零裁图率 .24 vs .18。
- **探针分歧出现在哪一回合**：组内答对减答错的 b 均值，第 1 回合 +.045，第 2 回合 +.055，第 3 回合 +.058。也就是第一次裁图后已出现约 78%。
- **CPC 准入量**：λ\* = .19；λ=1 时 advantage 方差相比 DAPO **增大** 10.8%，未达到推导稿里“降方差”的前提。

## 与论文的匹配（只列对应关系和前提，有没有效由用户判断）

| 我们的发现 | 对应层 | 论文怎么处理 | 论文的前提 | 前提在我们这里的状态 |
|---|---|---|---|---|
| F1：约 23% 的更新组来自不可答 / GT 有问题的题 | group / 数据 | DAPO 只按方差过滤，不看可答性。[OLR](https://www.alphaxiv.org/abs/2604.03993) 把噪声标签分成 inactive（策略复现不出来，只浪费样本）和 active（会被奖励强化），用 rollout 多数投票加历史一致性修正标签；[Noisy Data Destructively Affects RLVR](https://www.emergentmind.com/papers/2603.16140) 报告重新核实后真实噪声明显伤害 RLVR。（两篇只读了检索摘要，未精读） | 噪声要能被策略的多次采样识别出来 | 我们有人工的 L0 标签，不需要在线估计；needs_temporal 类单图不可答，答对只能靠猜 |
| F2 / E1：RL 之后，组内差异以“取证之后”为主（V\* 上 GRPO 51%、DAPO 53%、DTPO 74%） | 信用（最终回合）/ 辅助 loss | PAPO 的诊断是 67% 感知错误，加辅助感知 KL；VPPO 把梯度集中到视觉依赖高的 token；DTPO 提高最终段的权重 | PAPO / VPPO 都是单轮、单图任务，配方带熵 penalty，DAPO 基线会崩 | 我们是多轮多视图，DAPO 不崩；G1（读值一致性奖励）也针对取证之后的读值，E1 持平 |
| F2：原图已足够的配对占 34% | 同上 | VPPO 的 TAS / TGF、PAPO 都作用于“图已经在上下文里，用没用好” | 同上 | 这类配对与裁图策略无关 |
| F3：取证信号的组内 AUC 只有 .53–.57 | 信用 | Hτ、A+B、GRPO+A（我们的过程奖励）都以取证为信号 | 取证能区分对错 | AUC 低；这三个方法在 E1 上都未显著超过 DAPO |
| F4：全错组中 76% 取到过证据 | 采样 | Tree-GRPO、ARPO 分叉，Reinforce-Ada / Knapsack 加采样 | 补采能产生对的样本 | 多数全错组的问题不在取证 |
| F5：分歧在第一次裁图后已出现约 78% | 信用（首动作） | ARPO 在工具反馈后的熵升高处分叉；我们主线的首动作分叉 | 分歧集中在少数决策点 | 探针差值本身很小（+.045） |

## 没做的
- 尺度阈值没有校准；“取到证据”不等于“读对了”。读值和绑定是否正确，要对照 L2 看图复核（本次未做）。
- 纯 GRPO / DAPO 账本没有裁图框，组内取证分析用的是 DAPO-SB 和 GRPO+A 的账本；它们的后期策略与纯 DAPO / GRPO 不同，第 1–2 次更新的数据就是 A-SFT 起点。
- E1 V\* 的配对只有 99–150 对。
