# 各方法的学习信号审计：进入更新的数据 / 奖励 / 组内 advantage / 信用分配（2026-11-05）

只列事实与测量，不做原因分析。

- 数据来源：各 run 的训练 rollout 账本（每条轨迹一行：对错、终止方式、裁图数、生成 token；S / Φ / b 等过程字段按 run 而定），过滤类 run 的更新账本（每步保留的题号），以及 E1 轨迹。
- 脚本：`audit_signal.py`（输出 `audit_signal.json`）、`plot_audit.py`（输出 `figs/a1–a6`）。
- 训练曲线见阶段 README 的 14 张图（`stage_report_20261105`）。

## 1. 算法差异（设计层面）

| 方法 | 进入更新的数据（采样 / 过滤） | 奖励 r | 组内 advantage | 信用分配（advantage 如何分到回合 / token） | loss / clip |
|---|---|---|---|---|---|
| GRPO | 每步 128 题 × 8，全部进入；全对、全错组的 A=0 | V·Y | (r − 组均值) / 组 std | 整条轨迹同一个 A | token 平均；clip .2/.3 |
| DAPO | 只保留混合组（0.01 < 组均值 < 0.99），不足 128 组就继续生成 | V·Y | 同 GRPO | 同 GRPO | token 平均；clip .2/.28 |
| GSPO | 同 GRPO | V·Y | 同 GRPO | 同 GRPO；ratio 取序列级几何均值 | 序列内平均；clip 3e-4 / 4e-4 |
| GiGPO | 同 GRPO | V·Y | episode z-score + 1.0 × 锚点组 z-score | 锚点项只加在该回合 | 同 GRPO |
| RLOO / + 首动作分叉 | 同 GRPO | Y(1 − 0.01N) | 留一基线 | 整条轨迹；分叉版另有首动作辅助损失 | 同 GRPO |
| DTPO | 同 GRPO | V·Y | 同 GRPO | 同 GRPO | 中间回合 token 权重 0.5、最终回合 1；clip .2/.24 |
| SAPO | n=1 | Y | turn 级 GAE（共享 LM head 读 V/Q） | 每回合不同 | PPO + V/Q 损失 |
| G1 | 同 GRPO | V·(Y + 0.25·m·Φ_read) | 同 GRPO（z-score of r） | 整条轨迹 | 同 GRPO |
| Hτ | 同 DAPO（filter_key = accuracy） | V·(Y + 0.25·m·Φ_τ) | 同 GRPO | 整条轨迹 | 同 DAPO |
| A+B | 同 GRPO | V·(Y + 0.1·m·S) | 任务尺度：((y − ȳ) + (s′ − s̄′)) / max(std(y), 1/√8) | 整条轨迹 | 同 GRPO |
| A+B+C | 同 GRPO；384 行替换为证据续答行 | 同 A+B；续答行 V·Y | 同 A+B | 整条轨迹 | 同 GRPO |
| GRPO+A | 同 GRPO | V·(Y + 0.1·m·S) | 同 GRPO（z-score of r） | 整条轨迹 | 同 GRPO |
| DAPO-SB | 同 DAPO | V·Y | (Y − b_k) / std(Y)，不减组均值 | 第 k 回合用该回合前的探针 b_k | 同 DAPO |

所有 run 共同：A-SFT 起点；4k 池；seed 42；32 次更新 × 128 组；lr 1e-6；无 KL；max_grad_norm 1.0。

## 3. DAPO 过滤与补采了什么（`figs/a1`、`figs/a4`）

**每次更新的生成情况**（每轮生成 32 组）

- 生成轮数 7–9 轮，平均 7.69；第 1–4 步各 7 轮，第 29–32 步为 9 / 8 / 8 / 8 轮。
- 每次更新平均生成：混合组 135.9（用了 128，多出约 8 组未用）、全对 80.4、全错 29.7。
- 全对组在生成组中的占比：第 1–4 步 .275，第 29–32 步 .377。全错组：.127 → .115。

**题池的第二遍**

## 5. 口径上需要注意的事实

- **entropy**：日志里的 entropy 在更新 batch 上计算。DAPO 系的 batch 只含混合组，GRPO 系含全部组，所以第 1 步 DAPO 为 .448、GRPO 为 .424，同一起点、不同人群。第 25–32 步均值：DAPO .447、GRPO .448、DAPO-SB .359、Hτ .423、A+B .469、GRPO+A .436、GSPO .414（第 1 步 .383）。
- **裁剪**：所有记录了 grad norm 的 run，裁剪前的最小值都 ≥3.05，max_grad_norm 为 1.0，每一步都被裁剪。
- **训练正确率**（第 25–32 步均值，全部生成的 rollout）：DAPO-SB .636、Hτ .633、DAPO .626、DTPO .622、GRPO+A .616、GRPO .613、GSPO .610、G1 .609、A+B .608、RLOO .604、GiGPO .603、A+B+C .577。DAPO 系是两遍题池上的统计，GRPO 系是一遍。
- **训练裁图**（第 25–32 步均值）：GRPO+A 3.39、DTPO 2.75、GSPO 2.30、Hτ 2.19、A+B 2.18、DAPO 2.05、A+B+C 2.04、G1 2.04、RLOO 1.82、GiGPO 1.80、GRPO 1.65、DAPO-SB 1.60。
- 11-04 README 把 A+B 的 +0.82pp（净增 +18）与 +1pp 门槛并列；它的按题重采样 95% 区间为 [−1.36, +2.94]。
