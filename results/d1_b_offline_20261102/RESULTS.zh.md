# D1-B 离线结果 · 2026-11-02

选择按题启用逼近奖励。训练池 4,096 题中，3,289 题有符合条件的正证据框。其余 807 题只用原终答奖励，包括全部 50 道 absent 和 537 道 unanswerable。历史 DAPO 通过动态补采得到 7,872 个候选组，最终进入更新的是 4,096 个混合组，覆盖 2,648 个不同题目 ID。更新容量不能解释为每题恰好出现一次。

实验比较对象是原始 k8 DAPO。同池、同 seed 和 32 步是计划对齐的设置。原始 DAPO 在固定 E1 上答对 1,465/2,208（66.35%）。本次只离线重放已有轨迹，并在 CPU 上通过 EasyR1 奖励回调测试。D1-B 尚无训练后准确率。[冻结公式与判据](PROTOCOL.zh.md)

| 检验 | 观察 |
|---|---|
| 同题能否拉开分数 | V* 112 题 × 4 条 DAPO 轨迹，446 条有合法终答，2 条硬失败。109/112 题有组内分差。28 个有对有错的组中，同题正确样本得分较高的比例为 60.6%（平分计半，每题等权，按题 bootstrap 95% 区间 46.7%–73.5%）。另在训练侧已有的 27 个适用八样本混合组中，该比例为 56.7%。 |
| 能否分辨答对但证据引用错误 | 对一条真实答对的轨迹，将不能同时看到两个候选的引用换成能看到两者的引用。对另一条答对的轨迹，将能看到关键数字的引用换成裁掉该区域的引用。各自的最终选项与裁图完全相同，过程分分别维持 0.5087 和 0.5012。这两次引用替换是构造对照。 |
| 盲扫是否能得利 | 同一条有效轨迹改用单次整图裁剪，56/446 条得分更高。改用四宫格盲扫，63/446 条更高。重复最后一张裁图的 439 个可行对照全部同分。 |
| 多一次无目标信息的裁图是否有利 | 在仍有裁图额度的 439 条轨迹末尾追加一次整图裁剪，73 条涨分、366 条持平，平均过程分增加 0.0462。它测量的是奖励对追加动作的反应，模型训练后会不会这样做仍未知。 |

在 V* 有效轨迹中，组内过程分方差的 84.8% 来自目标覆盖率，13.1% 来自最大 IoU，2.1% 来自两项协方差。真实裁图的最大 IoU（多目标取均值）中位数为 0.026，目标覆盖率中位数为 1。把理想框对准各官方目标，再按环境最短边 56 像素扩展，148 个目标的 IoU 中位数为 0.668。因此，此处的实际低 IoU 不能单凭最短边约束解释。

**决定**：冻结的公式能衡量裁图与目标的几何关系，第二关要求的引用正确性不能从这些几何量中读出。按事前判据，正式 D1-B 训练停在离线验收处。D2/D3 未启动。

**材料边界**：V* 使用与评测源图按字节核对的官方框。两条引用对照中的数字题另用本次审查时重建的辅助框，仅供该案例核对。另一批已有线索标注的 88 道 E1 题（352 条轨迹）没有适用的正目标框，未纳入过程分统计。训练侧 27 组使用历史保存的实际呈现框，按原日志排除含非答案终止的组，旧账本不足以重验所有终答语法。E1 是开发评测。本次几何诊断不更改原始评分分母。
