# D1-B 冻结协议与四关判据（运行离线测量前写入）

选择按题 gate B；所有步均用逼近项。原始生成和更新预算参照 D0。适用题要求训练标注 L0 可回答、GT agree、L1 存在、角色属于该 unit 正证据、框有效且置信度非 low。单实体的主要文字或目标、多角色键值、集合实例、比较候选及关系双方、链节点、全局主图按显式角色表取用。附属身份上下文、负候选、LC、搜索范围不进入正框均值。其余题 m=0，保留原 Y 并从全部 Φ 的均值、方差及其分母排除。按 L0 和 L1 生成只含 UID、mask 和几何的训练侧索引；E1 专用于离线诊断，不进入索引。

V=1 要求轨迹无硬协议错误、未截断、有效终答，允许合法但答错的选项得过程分。R=V·(Y+0.25·m·Φ)。二元 Y/accuracy 的组均值以严格 (.01,.99) 门限过滤，先过滤再写复合奖励；原评分器用于开发验证/E1。Φ 为所有适用正框的 (历史实际裁图最大 IoU + 裁图并集覆盖该正框比例)/2 的均值，范围[0,1]。原图不计；只用原图坐标的实际执行框，另记执行后回执未呈现数量；因硬违规结束的轨迹总奖励一律零。零裁直答Φ=0、多框均值可漏关键键、整图覆盖饱和是预登记局限。不增加探索分、hint、额外奖励或逐轮 advantage。

离线验证使用训练侧已有真实8样本组，与冻结 DAPO E1 每题4样本分开。V* 以原图标识对接官方目标框；已审 E1 文本依据仅用作审计，LC 不作正证据。四关沿用 PRIMITIVES_ROUTE_A §6，分别检验：
1. 同 UID/同一采样组内分数是否有差异，混合组内正确与错误的排序（平分记半），分别报告 IoU/coverage/协方差对组内方差的贡献，不能按 token 或跨题相关替代。
2. 已有审查中的答对且引用错位与有支持的具体断言；只换最后的来源声明而保留选项、所有裁图时，是否仍能分辨。定向对照，不估计全库发生率。
3. 人工无目标信息的单次整图、四宫格完整扫图、重复同一框，与真实轨迹逐条配对；纯重复应完全不涨分，盲扫不应系统性胜过真实轨迹。
4. 同题不同裁数的配对差异，以及在同一轨迹最后追加一个允许的无目标信息裁图时是否获利。描述预算、零裁正确样本、收益及并列比例，区分相关性与构造反例。

准入决定：若答对而依据错的构造无法区分，或盲扫系统性胜过真实轨迹（在过半有效轨迹上严格增加），不将四关记作通过，不直接开正式训练。分别记作几何诊断结果；保留按原式作为几何基线的决策选项。固定比较，不根据 E1 调 λ、阈值或选择 checkpoint。
