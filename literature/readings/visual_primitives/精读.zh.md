## 1. 论文要解决的问题（§1）

- **Perception Gap**：细节看不清。作者说高分辨率裁图、动态切块（Thinking with Images）这类工作主要解决的是这一类。
- **Reference Gap**：论文的主题。原文："seeing is not reasoning. Even with perfect perception, MLLMs frequently suffer from logical collapse in tasks involving complex spatial layouts or dense object interactions." 自然语言没法在连续视觉空间里当作精确、无歧义的指针；在密集计数、多步空间推理中，"the model's linguistic 'thoughts' lose track of the visual entities they intend to reference, leading to cascading hallucinations"。
- **对已有“框进 CoT”工作的批评**（[6, 27, 32]，具体是哪几篇未查）：
  - 把 grounding 当作事后验证；
  - 局限在高分辨率 benchmark 上，那里的难点是“看”而不是“推理”；
  - 依赖大量人工标注。
- **他们的做法**：把点和框当作 "minimal units of thought"，穿插写在推理过程里，类比人用手指指着数、指着走迷宫，用来"reduce cognitive load and maintain logical consistency"。

## 2. Primitive 的定义与取舍（§2.3.1–2.3.2、§2.3.4）

- **两种 primitive**：
  - 框：`<|ref|>目标<|/ref|><|box|>[[x1,y1,x2,y2],...]<|/box|>`；
  - 点：`<|point|>[[x,y],...]<|/point|>`。
  - 坐标归一化为 0–999 的整数；多个实例从左到右排列。点不带物体名，方便表示轨迹这类抽象概念。
- **为什么优先扩大框的数据**，原文三条理由：
  - 框的标注相对确定，而点的标注有歧义：物体内任何一点都算对，遮挡时还可能落到前景物体上；
  - 框可以退化成点（两个角点）；
  - 框带宽高，信息更多。

## 3. 数据

### 3.1 预训练的框数据（§2.3.3）

- 抓取了 97,984 个 grounding 数据源，排除了所有 val/test split。
- **第一步，语义审查**：MLLM 每个源抽 3 张图打 0–10 分，判 KEEP/DISCARD。丢弃三类：无意义编码（如类别名是 "0"、"1"）、私人实体（如 "MyRoommate"）、含糊缩写或主观标签（如 "OK"/"NG"）。剩 43,141 个源。
- **第二步，几何审查**：丢弃三类：严重漏标（漏标率 >50%）；严重截断或偏移（稍松可以，切掉关键部位不行）；整图大框（>90% 面积，且三张图都这样）。剩 31,701 个源。
- 按类别每类最多采 1,000 张图，合计 4,000 万条以上样本。

### 3.2 冷启动数据（§2.4）：思考内容的结构

| 任务 | 规模 | 来源 | 思考的写法 | 校验与负样本 |
|---|---:|---|---|---|
| 粗粒度计数 | 约 1 万（含细粒度） | 密集检测数据集 | 三步：意图分析 → 一次性框出所有候选（batch grounding）→ 基于框汇总计数 | 严格校验：思考里的框必须和标注坐标一致、语法正确、和最终计数一致 |
| 细粒度计数 | 同上 | GQA 场景图 | 逐个扫描，按约束核对每个候选（sequential scan），每个都给框 | 构造计数为 0 的负样本 |
| 空间推理与一般 VQA | 9,000 | GQA 场景图 + CLEVR 合成 | 意图分析 → 物体定位 → 关系推理；拥挤场景用多属性约束唯一指定目标 | 负样本：目标或关系不存在时，要求依据视觉证据"faithful refusal" |
| 迷宫 | 460,000 | DFS / Prim / Kruskal 程序生成，三种拓扑 | DFS 探索：每一步用点标位置，碰到死路就回溯，最后输出验证过的路径 | 不可解迷宫：在解路径中段加墙；难度用网格大小控制，并保证分辨率足够看清 |
| 线路追踪 | 125,000 | 程序生成的 Bézier 曲线 | 起点 → 沿线的途经点 → 终点；**直的地方点稀，弯曲和交叉处点密** | 统一颜色模式，去掉靠颜色走捷径的可能 |

论文的定位：cold-start 是"small but high-precision"，用来"bootstrap instruction following and reward learning under our visual primitive output interface"（§2.4 开头）。

## 4. 后训练（§2.5）

1. **Specialized SFT**：数据中 70% 是通用多模态和纯文本，30% 是 primitive 数据；框和点**分开训练**，原文给的理由是"prevents mode conflict when the volume of specialized data is relatively small"。
2. **Specialized RL**：算法是 GRPO（超参沿用 [3]）。
   - **不监督思考里的 primitive**。原文："we do not explicitly supervise the visual primitives generated during the model's thinking process in the RL phase"。理由有两条：冷启动数据里的 primitive 已经严格校验过；RL 数据只需要图、问题和答案，容易扩大规模。
   - **Format RM**（0–1）：检查 primitive 格式和重复框，用来对付"SFT model falling into an infinite loop of box generation"。
   - **Quality RM**：一个 LLM 评审，输入是思考和最终回答，打 0 / 0.5 / 1 三档。检查五项：冗余；思考与答案是否一致；自相矛盾；框指向的是否是有意义的实体；reward hacking（"forcefully fabricating a fake ground truth identical to its own prediction"）。
   - **Accuracy RM**，分任务：
     - 计数：R = 0.7·exp(−3·|ŷ−y|/(|y|+1))；
     - 空间推理与一般 VQA：LLM 评审分别给思考和回答打分，取平均（输入包含标准答案）；
     - 迷宫：五项加权——因果截断后的探索进度、不可解迷宫的探索完整度、穿墙惩罚、最终路径是否合法、可解性判断是否正确；
     - 线路追踪：双向轨迹距离、起点终点到真值框中心的距离、连续性惩罚（最后一个点离所报终点太远就扣分，防止"jump to a guessed endpoint"）、答案是否正确。原文强调必须双向："The forward direction alone would allow the model to output only a few safe points near the start, while the reverse direction alone would not penalize hallucinated detours."
   - **RL 数据选择**：先用 SFT 模型对每题采样 N 次，按正确数分成 Easy（全对）、Normal（1 ≤ k < N）、Hard（全错），**只用 Normal**。
3. **Unified RFT**：用两个专项模型在数据池上采样，保留全部 Normal 和 5% 的 Easy，**从预训练底座重新做 SFT**，配置与冷启动 SFT 相同，得到统一模型 F。
4. **OPD**：F 仍不如两个专项模型，于是用反向 KL、全词表 logit 蒸馏，从两个专项模型蒸到 F。

## 5. 实验（§3）

- **规模**：底座是 DeepSeek-V4-Flash（284B 总参数，13B 激活）。800×800 的图在 KV cache 里只剩约 90 个条目（图 1）。
- **评测设置**：像素数低于 640,000 的图先放大；前沿模型的 thinking budget 统一设为 low。
- **表 1（摘录）**：
  - CountQA 64.9/74.1（Gemini-3-Flash 66.1/75.1）；
  - DS_Maze 66.9（其他模型 48.9–50.6）；
  - DS_Path_Tracing 56.7（其他模型 24.5–46.5）；
  - CV-Bench 88.4（Gemini 88.6）。
- **全文没有“有 primitive 对比无 primitive”的消融**：搜过 "ablation"，没有对应章节，§3 只有和前沿模型的对比与定性例子。
- **定性**（§3.4）：后训练数据里没有中文，但模型能用中文做带框的思考（附录有例子）。

## 6. 作者写的局限（§4）

1. 受输入分辨率限制，细粒度场景下 primitive 有时不准；作者认为可以和解决 Perception Gap 的方法结合。
2. 要靠显式触发词（例子里的 `[Trigger_Placeholder]`）才启用，模型不能自己决定什么时候用。
3. 用点解决复杂拓扑推理仍然很难，跨场景泛化有限。

## 7. 用主线视角回答六个问题

1. **比较的是哪几条路线？** 没有分支比较。GRPO 只在组内比较整条轨迹的奖励。
2. **信号的形式？** 三类：规则（格式、计数、迷宫、路径）、LLM 评审（质量、一般 VQA 的准确率）、标准答案。思考里的 primitive 只在迷宫和路径任务上与真值比较。
3. **信号给到哪里？** 全部是轨迹级奖励，经 GRPO 变成 advantage。迷宫和路径的奖励分项由过程中的点算出来，但最后汇总成一个标量，没有逐步的 advantage。
4. **额外计算记入成本了吗？** LLM 评审的调用量和 RL 前的 N 次采样分难度，论文都没有报告。论文报告的成本只有视觉 token 和 KV 条目数。
5. **成本口径和我们一致吗？** 不一致。他们没有工具调用，成本是视觉 token；我们算的是裁图次数（首裁和后续分开）和总 token。
6. **迁移边界？** 他们有 4,000 万级 grounding 预训练和 284B MoE 底座；primitive 不会执行，没有回看新图这一步；要靠触发词启用。我们是 4B，只做 SFT+RL，框会被执行并返回新的视图。

## 8. 与我们的对应（CC 的读法，供讨论）

### 8.1 我们的轨迹里已经有的“primitive”

- 每轮都是“思考 + `<grounding>{"bbox_2d":[x1,y1,x2,y2],"source":VIEW}`”。框是 [0,1] 坐标、相对 source 视图，**会执行**，并返回新的 observation；思考里用 `[original_image]`、`[observation_k]` 引用视图。
- 协议禁止在 caption 里写坐标（[协议](../../../protocol/CAPTION_V51.md) SYSTEM："Crop coordinates belong only in the action"）。E1 实测思考里出现坐标的轮次比例（`coord_status`）：
  - SFT（B3_sft）：2/4,403；
  - k8 GRPO / DAPO / GSPO / GiGPO：15/6,415、17/6,827、23/7,205、17/6,620。
- A-SFT 的行为分布（研究者整理的 SFT 统计）：
  - 直答 / 1 裁 / ≥2 裁：2,093 / 1,141 / 749 条；
  - locate / re_examine / fallback：1,943 / 907 / 120 轮；
  - HOLD 88 轮，REVISE 2 轮，abstain 0。

### 8.2 论文元素 → 我们这边的对应物

| 论文 | 我们这边的对应物 | 现状 |
|---|---|---|
| 思考里的框，用来锚定实体（Reference Gap） | 裁图框（指向区域），加上视图引用（指向某张视图）；实体本身仍用文字指代 | 已有；思考里写坐标约 0.2–0.3%，SFT 中几乎没有 |
| 计数：意图 → batch grounding → 汇总 | Step 1 `locate` → 裁图 → `commit` + `CALC` | 结构相近；我们不要求逐个框出实例 |
| 细粒度：逐个核对约束 | `re_examine` 逐个候选核对 | 907 轮 |
| 迷宫 DFS 回溯 | `fallback`（放弃无效分支，换区域） | 120 轮，占比低 |
| 线路追踪：途经点疏密随难度变化 | 裁图粒度随难度变化（粗看 → 细看） | 无对应的奖励 |
| 负样本 faithful refusal | `abstain` / `UNCLEAR` | A-SFT 里 0 条 |
| 冷启动校验：primitive 必须和标注一致 | 无：教师裁图框不和真值比较，RL 题池没有真值框 | 缺真值 bbox |
| Format RM（重复框） | 硬检查（违规记 0）；系统提示要求不重复等价裁图，但不检查 | 重复裁图没有检查（例：T03 GiGPO） |
| Quality RM：思考与答案一致、自相矛盾 | 无 | E1 样例里出现过（T03 DAPO、T04 GRPO、T07 GRPO / GSPO） |
| 路径奖励：双向距离 + 端点 + 连续性 | 导师 10-31 的目标逼近：maxIoU(目标框, 历史裁图框) + 目标框被覆盖的比例（[导师 10-31 要求](../../../context/MENTOR_20261031_PROCESS_SIGNAL.md)） | 需要归一化的真值 bbox |
| 迷宫奖励：探索进度 / 完整度 | 导师 10-31 的探索程度：历史裁图框并集的覆盖面积；前期用探索、后期用逼近，用 gate 切换，不做加权和 | 同上 |
| RL 只用 Normal 难度题 | DAPO 的在线过滤（.01/.99） | 已有（DAPO） |
| 触发词启用（局限 2） | 首动作分叉监督（v53），学的是何时裁图 | 已在做 |
