# CounterCredit 精读（arXiv 2609.22910v1）

Kunyu Peng、Junming Liu、Ruiqi He、Qingzhuo Wang、Jianzhong Qi、Xianhui Liu（同济 / 南开 / 墨尔本大学）。*When Should a VLM Look? Paying Only for Visual Calls That Were Needed and Used*。预印本，2026-09-19。下文页码为 PDF 页码。

## 一句话
对每一次返回图像的裁图调用，在它被实际发出之前的同一前缀 h_i 上做三次打分——直接作答、真实裁图、随机同尺寸裁图——得到“决策价值 D”和“证据价值 E”，两者都超过死区才给 cashback，其余已执行调用都付 rent；该价格加进 0/1 结果奖励，并用“结果通道归一化 + 价格通道只中心化”的双通道 GRPO 优势训练（Eq.2–7，pp.4–6）。

## 问题与设定
- 智能体：Qwen2.5-VL-7B-Instruct，先用 6,960 条 Mini-o3 轨迹冷启动，再做 GRPO（§4.1 p.6；附录 B/C）。唯一工具是裁图。每轮写 `<think>`，然后写 `<grounding>`（框 + source，返回裁图）或 `<answer>`（附录 E，pp.21–22）。每条 rollout 最多 6 次工具交互（附录 C p.19）。
- 结果奖励 r_out ∈ {0,1}，自由问答由 GPT-4o 判（500 条人工核对 497 条一致，99.4%，附录 D p.20）。
- 作者的观察（Abstract, Fig.1, Table 7）：冷启动检查点上“既被需要又被用到”的调用只有 10% 到 12%（Table 7 base rate：V* 11.8、HR-4K 9.8、HR-8K 10.4）；结果奖励付钱的调用里，通过两项检验的占 12.8%（V*，Table 7，基准为 11.8%）。

## 方法
**三个分支（同一 h_i，§3.1 p.3，Fig.2a）。** h_i 是调用前的完整前缀，以该调用前的 `<think>` 块结尾（附录 E p.21）。
1. 直答：(h_i)；
2. 真实观测：(h_i, c_i, o_i)，即策略真实发出的调用及其真实返回的裁图；
3. 随机观测：K=3 个 (h_i, c_i, õ_ik)，调用文本 c_i 不变，只把返回像素换成原图上均匀随机采样的同尺寸块。

**打分（Eq.1）。** U_θ(p) = π_θ(y | p,e) / Σ_{a∈O} π_θ(a | p,e)：金标选项概率在选项字母上重新归一；e 是追加的固定提问“Based on everything so far, answer the original question now. Reply with the option letter only.”，assistant 回合预填 `<answer> `（附录 E p.22）。三个分支用同一个 e。自由问答用参考答案的逐 token 平均对数概率，死区 ε_free = 0.44（附录 C）。每个分支是一次不生成的前向（附录 C p.20）；论文里的探针没有采样续写到轨迹结束。梯度停止（p.4）。

**价值与价格。**
- D_i = U_real − U_now（Eq.2）；E_i = U_real − (1/K)Σ_k U_rand,k（Eq.3）；q_i = min{E_i, D_i}（Eq.4）。Prop.1：q_i 等于相对“λ 概率直答、否则随机裁图”这类参照的最坏情形优势。
- v_i = r_out · a_i · 1[q_i > ε]（Eq.5），ε = 0.05，由随机块“留一法”零分布标定（假验证率 V* 2.39%，HR-4K 2.51%，附录 C）。
- P(τ) = min{C, γ Σ_{i∈V}(q_i − ε)} − ρ(n(τ) − |V(τ)|)，R(τ) = r_out + P(τ)（Eq.6）。γ=0.5, ρ=0.05, C=0.7, n_max=6。错误或未作答的轨迹不跑探针，每次调用都付 ρ（附录 C、Alg.1）。Prop.2：因 ρ·n_max<1，任何正确轨迹的 R ≥ 1−ρ n_max = 0.7，高于任何错误轨迹。
- 优势（Eq.7）：Â_j = (O_j − Ō)/max{std(O), σ_min} + (P_j − P̄)，σ_min=0.15；组内无正确 rollout 时价格优势置 0（p.6）。

**作用位置。** 任务奖励（Eq.6 把 P(τ) 加到 r_out）和信用分配的归一化方式（Eq.7）；没有辅助损失，没有 SFT 数据改动。Â_j 只带 rollout 下标 j，论文未说明按 token 或按调用拆分（已查 §3.5、附录 A.6、C、Alg.1）；逐调用的 q_i 先被累加成 P_j（Alg.1 第 9–15 行）。训练时需要金标答案 y。

**额外计算。** 每条正确轨迹、每个合格调用 K+2 次打分前向（p.6）；每步约 2,200 个合格调用；训练步时 2,972 s（CounterCredit）对 2,881 s（同样跑探针只记录的 outcome-only），关掉探针为 2,320 s，即相对标准 outcome-only 流水线 1.28 倍（附录 C pp.19–20）；推理无探针开销。

冷启动：Mini-o3 发布的 7,267 条中保留 6,960 条。RL 池：VisualProbe 4,000 + DeepEyes 24,000（16,800 视觉搜索、3,600 ArxivQA、3,600 ThinkLite-VL）= 28,000，去重 26,600，去污染 26,200（与全部评测图 pHash 汉明距离 ≤5），格式过滤 25,700，难度过滤（冷启动检查点采样 8 次；0/8 删，1–7 保留，8/8 随机留一半）= 16,000（附录 B p.18）。RL：3 个 epoch、188 步、每步 256 prompt × 8 采样、lr 1e-6、无 KL/熵正则、8×H100（附录 C p.19）。所有 RL 臂同一列表。

## 作者承认的边界
- “The decision value does not separate the information in the crop from the effect of eliciting an answer at a prefix where the policy had decided to crop.”（§5 p.10）
- 证据价值只对裁图有定义（需要匹配的空返回）；文本/结构化输出工具没有对应的零分布。效率指标由奖励所用的同两个对比构成，“an evaluation defined apart from the reward would settle the question”（p.10）。
- 附录 G（p.30）：每个调用的价值之和不等于轨迹的价值；金标分数饱和时验证变弱；对 D≤ε 的“确认性查看”也收 rent，是否影响分布偏移下的稳健性“was not tested”；随机块未筛选，含目标时会拉高参照、压低 E，“errs toward under-verification”；开放问题含证据跨多次调用累积、更多基座、“longer training in which the policy could adapt to the probe”。
- 附录 A.8（pp.17–18）：所有分数都是策略自己的金标概率；“We make no claim that the counterfactual values identify a causal effect of the pixels on the answer, and no convergence claim for the optimizer”；Prop.3 的前提（假验证率）是用冷启动随机块零分布的代理估计，训练中不受控。
- 检索附录后论文未提供：多种子的消融臂、Qwen3-VL-8B 上的奖励消融、CodeV/FaithEyes 奖励的重训（只做了审计）、探针用采样续写代替即时提问的版本。

## 与我们的关系
**指导问题：同状态直答／真实裁图／随机裁图分别比较什么，信号送到哪里？**

| 比较 | 论文中的量 | 回答的问题（论文表述） |
|---|---|---|
| 真实裁图 vs 直答 | D_i（Eq.2） | 这次看是否被需要 |
| 真实裁图 vs 随机同尺寸块 | E_i（Eq.3） | 返回的像素是否被用到 |
| 直答 vs 随机块 | 不直接比较；只作为 Prop.1 里 B(λ) 的两个端点 | — |

- 信号去向：min{E_i, D_i} 逐调用进入 Eq.6，汇总成每条 rollout 的标量 P(τ)，加到 0/1 结果上；Eq.7 中以第二通道进入 Â_j。送达对象是整条 rollout 的优势（论文未说明 token 级拆分），不是对某次首动作的监督目标。
- 作用在奖励/信用分配；没有辅助损失。

**与我们计划的首动作分叉的对照（事实）：**
1. 分支的取值方式：论文用一次前向读出“金标选项概率”；我们的计划是从同一前缀 h 分别 rollout“直接作答”与“裁图后继续”各约 4 条，用平均回报之差。
2. 真实分支的内容：论文的真实分支是该 rollout 实际采样到的那一次调用及其裁图，之后立即追加提问作答（不继续生成）；“完整 rollout”的准确率另在 Table 9 作评估用。我们计划的“裁图后继续”分支会继续到作答。
3. 随机裁图分支：论文有；我们的计划里没有对应分支。
4. 起点：论文在每次已执行的调用（含后续调用）、且仅在正确且合格的轨迹上探针；我们计划的是第一个 `<answer>`/`<grounding>` 之前的前缀。论文的 h_i 以该调用前的 `<think>` 块结尾，策略已写出要裁图的推理。
5. 依赖金标：论文探针读金标概率；我们的回报是最终选项对错 Y（可选 R=Y·(1−λN)）。
6. 论文中“直答分支”只用于判断单次调用是否值得；没有用它去监督“是否该发出第一个调用”这一动作本身（论文未说明此用法）。
7. 论文的 table 9 在第一次调用处停下再作答，与我们分叉的“直答 vs 裁图”形式相近，但那是评估而非训练信号。
8. 论文的价格项对每个未验证调用收固定 rent ρ=0.05，所有臂的调用上限均为 n_max=6（附录 C p.19）；我们的成本账另计首次/后续裁图数与处理 token。

## 读后要回答的问题
1. 论文中的 U_real 是裁图后立即提问的概率，我们分叉里的“裁图后继续”回报包含后续步骤；这两种取值在同一前缀上给出的差在符号和大小上何时一致？
2. “直答”分支在论文里是在已写出“要裁图”的推理之后强行提问（作者自述的局限）；我们的 h 取在 `<think>` 之前还是之后？
3. 论文把 q_i 汇总成 rollout 标量 P_j；它没有给出把信号只送给第一个动作 token 的版本，该版本在其设定下是否可算（论文未说明）？
4. 论文探针只在正确轨迹上运行，错误轨迹的每次调用一律付 ρ；对应到我们的分叉，错误前缀是否也要分支？
5. Table 9 只列出 SFT、outcome-only、CounterCredit 三个臂的“无调用/随机/真实/完整”；TACO 式臂和各消融臂的同类数字论文未给出。
6. 论文的 spurious-call 率由训练目标同一对对比定义；在我们的成本账（首次/后续裁图数 + 处理 token）下，对应量如何单独测？
