## 0. 一句话目标

在下面固定的设置里，设计一个改动落在 **group advantage / 信用分配** 的算法：
- 不改奖励，任务奖励只保留 R = V·Y；
- 让 E1 超过 DAPO（.6635）；
- 要能用上我们已有的 L1 / L2 标注；
- 要符合导师的构造思路（第 2 节）。

## 1. 任务与固定设置（不改）

**模型与协议**
- Qwen3-VL-4B，从 A-SFT 起点做 RL（A-SFT 的 E1 为 .567）。
- caption v5.1 多轮裁图协议：每轮一个 `<think>` 加一个动作，动作是 `<grounding>{"bbox_2d":[x1,y1,x2,y2],"source":view}</grounding>` 或 `<answer>X</answer>`；每题最多 8 次裁图。
- 环境把裁出的视图作为新图像放进上下文；回执和图像 token 的 loss mask 为 0。
- 奖励 R = V·Y：合法结束且选项正确为 1，否则为 0，放在最后一个 assistant token 上。

**数据**
- rl4k 训练池：4,096 题，原图互不重复（MME-RealWorld / WorldBench / MMMU-Pro）。
- E1 评测：552 题 × 4 次采样 = 2,208 条（MME-RealWorld / V\* / WorldBench / MMMU-Pro）。**E1 与 rl4k 没有交集**。

**训练配置**
- EasyR1（verl），vLLM rollout。
- 每步 128 题 × n=8，共 32 步（每题只过一遍）；actor mini-batch 32 题，每步 4 次更新；ppo_epochs 1。
- lr 1e-6，max_grad_norm 1.0，无 KL，token 平均 loss，clip .2/.3（DAPO 为 .2/.28）。
- seed 42，**单 seed**（导师要求不做多 seed）。

**我们设置下必须遵守的机制事实**（都已实测）
- pg_clipfrac = 0、ppo_kl ≈ 1e-5：clip 从不触发，改 clip 或 ratio 门的方法没有作用点。
- 每步裁剪前的 grad norm 在 3–17 之间，**每步都被裁到 1.0**：整体放大或缩小 advantage 不改变步长，只有 token / 轨迹之间的**相对权重**会改变梯度方向。
- micro-batch 只有 1 到几条轨迹，统计量不能在 micro-batch 内算。
- 日志里的 "entropy" 是采样 token 的 −log π（温度 0.7），不是全词表熵。
- E1 按题重采样的 95% 区间约 ±2 个点。

## 2. 导师的构造思路（原话要点，最高优先）

1. **信用分配的四种情况**：
   - 用工具后由错变对 → 给有效工具分支信用；
   - 由对到对 → 不把功劳分给冗余工具；
   - 错了仍错 → 不对必要但失败的探索统一处罚；
   - 由对变错 → 把责任归到误导性工具。
   导师说后续“用**势能方程**来做信用分配”。
2. **逼近 / 探索**：
   - agent 每一步应当离目标更近，对整张图的探索也越来越多；
   - 逼近 = maxIoU(目标框, 到这一步为止所有裁图) + 目标框被覆盖的比例，归一化到 [0,1]；
   - 探索 = 到这一步为止所有裁图的并集面积 / 原图面积；
   - 前期用探索作信号，中后期用逼近作信号；**两者不能加权和**，否则找到目标后继续扫图仍能得分；
   - 状态切换用 max(逼近分, 探索分)。
3. 任务奖励是主要的、必须有的，过程奖励是额外构建。改 reward 本质上是为了得到更好的 advantage；梯度与 advantage、重要性比、clip 强相关。
4. 不复刻 PAPO / DVRP 这类方法；先把机制做 work，optimizer 可以迁移。
5. 用户补充（11-05）：**现在的方向是 reward shaping 不进 reward，而是在 advantage 部分做**。

## 4. 审计得到的事实（只列测量）

报告：`results/audit_signal_20261105/AUDIT_SIGNAL.zh.md`、`results/diag_d0_20261105/{D0_REPORT,AUDIT_PSI}.zh.md`。

1. **DAPO 的优势在进入更新的数据**：
   - GRPO 每步 128 组里平均只有 72 个混合组，其余 advantage 为 0；DAPO 每步 128 个全是混合组，每次更新平均生成 7.7 轮、丢掉约 80 个全对组和 30 个全错组；
   - DAPO 题池过了两遍，1,447 道题被更新两次；
   - 两者混合组的难度分布几乎相同；
   - DAPO 相对 GRPO 的净增按 A-SFT 难度分档（0/4…4/4）：+17、+5、+2、+15、+15。
2. **组内零和是硬约束**：
   - 正负 advantage 质量比（token 加权）：减组均值的方法都在 .91–.97；
   - DAPO-SB 为 2.23（同时 entropy .448 → .341，E1 −2.22）。
3. **把过程分加进 reward 再整组 z-score 是构造缺陷**：
   - 8 条全对或全错的组里，只要 S 有差异，λ 就会在标准化时被抵消（S 差 .01 和差 .8 都给出约 2.47 的 advantage）；
   - 这部分占全部 advantage 质量的 28%；分层写法下降到 0.3%（第 1 步实测 1.1%）。
4. **组内对错的差异大多不在“取证”上**（可判题的混合组配对）：
   - 尺度门口径：原图已足够 34%，两条都没取到证据 35%，取证差异 15%，取证之后 11%；
   - 纯几何口径：取证差异 24%，取证之后 22%。
   - E1 V\*（官方框）上，RL 之后“两条都覆盖了目标、一对一错”占多数：GRPO 51%、DAPO 53%、DTPO 74%；A-SFT 是 15%，而 A-SFT 的取证差异占 45%。
5. **组内能区分对错的信号都弱**（答对比答错得分高的配对比例，即 AUC）：
   - 停止探针 b_last .61；几何覆盖 / 证据尺度 .57；裁图数 .50；生成 token .48。
6. DAPO 丢掉的全错组里，76% 至少有一条取到过完整证据；50% 只看原图就已足够。
7. **约 23% 的 DAPO 更新组来自 L0 标为不可答或 GT 有问题的题**（主要是 needs_temporal 406 题；题池里这类题占 19%）。这些组平均每 8 条答对约 3 条。
8. **探索阶段很短**：在“碰到目标即逼近”的口径下，起点就有 85–93% 的第一张裁图碰到目标；4–8MP 的图和目标面积 <0.1% 的题，探索更长。
9. **几何势函数的代数限制**（两席推导，`design/` 之外的本地稿）：
   - 同一个几何进展可以对应导师的四种情况中的任何一种；
   - Ψ 单调不降，表达不出“工具让结果变差”；
   - 回合式 Ng 势函数 shaping 策略不变，因此在期望上实现不了四种情况；
   - 整图裁图的覆盖项为 1，prox ≈ .5；用户判断大裁图在实际轨迹中是边际问题（含 ≥90% 面积裁图的轨迹，起点 0.07%，后期 4%）。

## 7. 本质上卡在哪里（我们的测量能支持的部分，不是因果结论）

- 唯一测出显著提升的是“进入更新的数据”（DAPO）。所有改 reward 或信用的尝试，差异都在 ±2 个点的分辨力以内。
- 已用过的过程信号（几何覆盖、尺度门、读值一致、停止探针），在组内区分对错的能力都弱（AUC .53–.61）。而 RL 之后，组内对错差异的多数落在“看到证据之后”。
- 过程信号进入 advantage 的写法本身出过两次问题：
  - 加进 reward 再整组 z-score，全对 / 全错组被放大，占 28% 的 advantage 质量；
  - 用非组均值作基线（DAPO-SB），打破了组内零和。
- L2 能刻画“看到之后读对 / 读错 / 绑错”，正好对应上一条的多数差异，但目前落不到轨迹上：
  - 精确的规则抽取几乎没有信号（2.3%）；
  - 宽松的抽取主要测到写法（47%）。

## 8. 请交付

1. **建模思路**：你如何理解“势能”在这里应当是什么（状态上的什么量），以及它为什么应当进入 advantage 而不是 reward。说明它与导师四种信用情况、逼近 / 探索构造的对应关系。
2. **完整算法**：
   - 公式（符号先定义）：每条轨迹或每个回合 / token 接收的 advantage；
   - 组内零和怎样保持（或为什么可以不保持）；
   - 正负质量比的代数预测；
   - 全对 / 全错组如何处理；与 DAPO 的过滤能否组合；
   - 基座用 GRPO 还是 DAPO，理由是什么。
3. **L1 与 L2 怎样用**：
   - 若使用 L2，怎样把它落到轨迹上，同时避开第 5 节的两个问题：精确规则覆盖太稀，宽松规则测到写法；
   - 不允许在训练中让模型额外生成解释，也不要依赖在线大模型评判；
   - 是否需要改动 rollout（例如同状态分叉、强制作答探针）；如果需要，额外成本是多少。
4. **反例**：至少覆盖整图裁图、平铺扫描、找到后继续扫图、原图已可读、不可答题、答对但读错、答错但读对。逐个给出公式下的数值。
5. **开训前的离线准入**：
   - 能用已有账本和轨迹算的量，以及每个量的通过线；
   - 现有账本：训练 rollout 有每条轨迹的裁图框、对错、生成 token、S / prox / explore / gate，DAPO-SB 账本还有每回合的停止探针 b；行为审计数据有 12,576 条带全文的轨迹；E1 轨迹有全文。
6. **预登记**：相对 DAPO 与 GRPO，E1 总分、分源、裁图数、零裁图率、entropy、正负质量比的预期方向和量级。
7. **新颖性**：与 TRACE、VinePPO、GiGPO、Tree-GRPO、ARPO、Stratified GRPO、GDPO、HDPO（只在答对轨迹之间比较效率）、PAPO / VPPO 的区别。

**约束**：
- 任务奖励 V·Y 不变；
- 公共设置不变，单 seed；
- 不为每种失败现象单独加奖励项，方法要简单直观；
