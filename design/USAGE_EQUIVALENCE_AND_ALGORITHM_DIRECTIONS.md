# "使用"的几何等效与算法方向（供云端 Pro 设计）

2026-11-02。研究者决定：**引用≠使用的精确验证不做**，冻结"最后一次裁图 ≈ 使用"为工作假设；本文给出等效视角与候选算法，供 Pro 做具体设计。GPU 已停止，无训练进行。

## 0. 假设升级：从"引用=使用"到"末裁=使用"

D2 冻结的是"commit 引用 = 使用"。研究者提出"最后裁图 ≈ 使用"。实测（E1 V\* 112 题官方框，444–448 条有效轨迹/条件）：

| 条件 | 最后裁图 ∈ 引用集 | 引用集恰为 {最后裁图} | 引用为空 | 覆盖：只用末裁 vs 用引用 |
|---|---:|---:|---:|---|
| A-SFT | 0.716 | 0.669 | 0.270 | 0.595 / 0.596 |
| k8 GRPO | 0.929 | 0.830 | 0.049 | 0.805 / 0.814 |
| k8 DAPO | 0.924 | 0.846 | 0.043 | 0.808 / 0.832 |

结论：RL 后末裁与引用高度一致（92–93%），覆盖信号损失 ≤0.024。**末裁代理优于文本引用**：纯几何、无解析、免疫"写引用不裁图"；攻击面只剩"末次大区域扫图"，用精度项约束（见 A）。SFT 条件较弱（27% 不引用、30% 引原图），若从 SFT 起训需注意。数据 [lastcrop_vs_cited.json](../data/usage_equivalence_20261102/lastcrop_vs_cited.json)。

## 1. 等效视角：设计空间是三元组

任何候选过程信号 = **(状态函数 Φ， 信用分配规则， 使用代理)**。两个已证事实约束设计：

1. 轨迹级 advantage（当前 GRPO）下，势能差分、覆盖、recency 加权**全部塌缩为裁图集合的同一函数**——Σ(Φ_{t+1}−Φ_t) = Φ_T−Φ_0。它们的差别只在"信用怎么分到动作上"。
2. BPTT 不可做（环境不可微），其**等效物**有二：
   - **几何 leave-one-out**：动作 i 的贡献 g_i = Φ(S) − Φ(S∖{i})，裁图是集合元素，完全可离线计算；
   - **事件级过程 GRPO**：把 g_i 放在第 i 次裁图动作的 token 位置（DeepSeekMath §4.1.3 有出处），优化器不变。

即："回传信用" ≡ "集合边际贡献" ≡ "势能增量落在动作上"——三种说法一个对象。

## 2. 候选算法（simple & clear）

**A. 末锚定（用户假设的直接形式）**
Φ_use = 证据节点被**最后一次实际裁图**覆盖的均值；加精度约束：末裁与证据节点的交 / 末裁面积 ≥ τ（或末裁面积 ≤ p×整图），防"末次整图刷满"。
- 等效于：把"使用"从文本搬到终末动作。实现量最小（reward_d2.py 改一行：cited_views=[n_crops]）。
- 攻击面：τ/p 的选取；多节点题末裁只能盖住部分节点（与 B 合用可解）。
- 已有数据可定 τ：V\* 理想框的 precision 分布（好裁图 precision 中位可算）。

**B. 边际增益信用（导师势能方程的事件级落地）**
对每次裁图 i：g_i = [Φ(S) − Φ(S∖{i})] × precision_i，Φ = 证据节点覆盖状态；g_i 记在动作 i 的 token 上（过程 GRPO），轨迹总和 = Σg_i。
- 等效于 BPTT 的信用回传；与导师"每一步离目标更近/探索更广、势能做信用分配"同构。
- 天然抗投机：重复裁图 g=0；追加无信息裁图 g=0。首裁整图 g 大 → 乘 precision_i（交/裁面积）压制。
- 实现边界：EasyR1 advantage 计算要支持 token 位置的逐事件奖励（改 advantage 与 mask，不动优化器）；离线可先用四关验 g_i 的判别力。

**C. recency 折扣谱系（把用户假设与导师公式连成一条线）**
Φ_γ = Σ_i γ^(T−i) × (裁图 i 的新增覆盖)。γ=0 退化为 A（末锚定），γ=1 退化为 D1 覆盖。一次超参连接两个已冻结端点，可离线扫 γ 取判别力最高点，避免再发明新形式。
- 攻击面随 γ 单调变化（γ 大 → 靠扫图，γ 小 → 靠末锚），离线可画整条曲线。

**D. 使用一致性观察哨（不进奖励，进监控）**
训练中持续记录：末裁 ∈ 引用集的比例、引用为空率、cite-all 余量。这三项是导师 10-31 所说 reward hacking 的直接观测面；训练后若末锚定比例下降 = 模型在用别的东西作答，假设失效的早期信号。

**E. 多节点 min 聚合**（Pro 早前建议，重申）：keyed_set 类 Φ 聚合用 mean+min，防漏关键表头。
