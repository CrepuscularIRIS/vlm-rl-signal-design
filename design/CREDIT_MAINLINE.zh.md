# 设计主线：预算化势能信用（草案，2026-11-04）

状态：设计草案，尚未训练。本文把截至 11-04 的实验事实、导师的方向和候选算法整理成一条主线，作为保留版本。文中凡标“提案”的部分都未经实验验证。

## 0. 一句话

> 不再设计新的过程奖励。结果奖励 $V\cdot Y$ 保持不变，只改变**结果信用怎样分配到轨迹和回合**：每条轨迹的信用总额固定，末轮的份额得到保障；中间工具回合的信用按“这次看图让答对的可能性变化了多少”（势能差）来分配。

## 2. 已有的实验事实（这条主线据此设计）

### 2.1 四种过程奖励的共同结局：被奖励的指标上升，E1 基本不动

| 尝试 | 奖励对象 | 结果 | 出处 |

| Hτ（DAPO 基座） | 裁图覆盖 L1 框 | 裁图 2.09 → 2.55 张/条；E1 .6635 → .6508 | `results/sg_20261104/audit/AUDIT.zh.md` §8 |
| G1（GRPO 基座） | 作答文本读值与 L2 一致 | 读值一致性 .55 → .69；E1 .6390 → .6395 | `results/g1_rread_20261103/` |
| A+B / A+B+C（GRPO 基座） | 尺度门控取证分 S | 裁图 1.91 → 2.40 张/条；E1 .6472 / .6395 | `results/sg_20261104/` |
| Φ_bind（未训练，只做了审查） | 写对“行—列—值”绑定 | 抽检 30/30 答对轨迹都写对了绑定，答对轨迹之间的分差来自写法能否被识别 | `results/behavior_20261104/BIND_AUDIT.zh.md` |

- 混合组里，任务奖励已经把答对的轨迹排在答错的前面；过程分只能在结果相同的轨迹之间重新排序，而排序依据是代理指标（裁得多不多、写法是否规范）。
- 全错组里可靠的可教差异很少：DAPO 自己的轨迹中，1,191 道可核验题只有 22 组。

### 2.2 DAPO 与 GRPO

- advantage 公式相同。DAPO 只让有对有错的组进入更新，不够就补采：生成 7,872 组、进入更新 4,095 组，覆盖 2,648 道不同的题，其中 1,447 道题更新了 2 次以上；累计 token 是 GRPO 的 2.27 倍。E1 .6635 vs .6390。

## 3. 算法（提案）

记号：题目 $q$，每题 $G=8$ 条轨迹；轨迹 $i$ 有 $K_i$ 个中间（工具）回合和一个末轮（作答）回合；$L^F_i$ 为末轮训练 token 数，$L_{ik}$ 为第 $k$ 个中间回合的训练 token 数；$Y_i\in\{0,1\}$ 为合法终答的正确性。

### 3.1 第一部分：结果 advantage 不改

$$
A_i=\frac{V_iY_i-\overline{VY}}{\operatorname{std}(VY)+\epsilon}
$$

不增加任何过程奖励，不使用标注评分器。动态采样沿用 DAPO（见 3.5）。

### 3.2 第二部分：每条轨迹的信用总额固定（来自 HB-GRPO，`papers/Advantage.md`）

给轨迹 $i$ 的训练 token 分配权重 $w_{it}\ge 0$，并要求 $\sum_t w_{it}=1$，于是 $\sum_t w_{it}A_i=A_i$：写得更长、裁得更多，只能改变信用落在哪里，不能凭空多拿信用。首版的预算比例为：

| 轨迹结构 | 末轮 | 全部中间回合合计 |
|---|---:|---:|
| 直接作答 | 1 | — |
| 有 $K\ge1$ 个中间回合 | $2/3$ | $1/3$ |

### 3.3 第三部分：中间回合的信用按势能差分配（VPC）

**势能**：只看已经得到的视图时，被迫作答答对的概率：

$$
\Phi(s_k)=\pi_{\theta_{\text{old}}}\big(y^\star\,\big|\,q,\;v_0,\dots,v_k\big)
$$

- $v_0$ 为原图，$v_1,\dots,v_k$ 为前 $k$ 次裁图得到的视图。
- 只放题面和视图，**不放模型自己写的思考文本**，避免模型写一句猜测就把势能抬高。
- 读取正确选项字母这一个 token 的概率，只需一次前向，不需要采样。

**第 $k$ 次工具调用的势能差**：

$$
\delta_{i,k}=\Phi(s_{k+1})-\Phi(s_k)
$$

**前后相消**：$\sum_k\delta_{i,k}=\Phi(s_K)-\Phi(s_0)$。工具阶段的信用总量只取决于整个看图过程把答对概率提高了多少，与裁了几次无关。

### 3.4 合并后的 token 级系数

$$
\widetilde A_{i,t}=
\begin{cases}
\dfrac{2}{3}\cdot\dfrac{A_i}{L^F_i}, & t\in\text{末轮}\\[10pt]
\dfrac{1}{3}\cdot\dfrac{c\,A_i+\beta\,\delta_{i,k}}{L_{ik}}, & t\in\text{第 }k\text{ 个中间回合}\\[10pt]
\dfrac{A_i}{L^F_i}, & \text{直接作答的轨迹}
\end{cases}
$$

- $c\in[0,1]$ 决定中间回合保留多少结果信用：$c=0$ 表示中间回合只拿势能信用，$c=1$ 等同于 HB-GRPO 的平均分配。首版建议 $c=0$。
- $\beta$ 是势能信用的尺度，因为 $\delta\in[-1,1]$。

每个题组的 loss 是 8 条轨迹 $\sum_t\widetilde A_{i,t}\,\ell^{\text{PPO}}_{i,t}$ 的平均，再在有效组之间平均。重要性比率、非对称 clip、dual clip 沿用现有实现，归约跨 rank、跨梯度累积保持一致。

### 3.5 采样（DAPO 动态采样的扩展）

DAPO 只保留有对有错的组。提案额外保留全对或全错、但组内存在 $\lvert\delta\rvert>\epsilon_\delta$ 的组；这些组只更新中间回合的 token（末轮的 $A_i=0$）。这为 DAPO 从未更新过的那部分难题（1,448 道）提供了一个**不依赖标注**的信号来源，也回应了导师提到的“被某种难度主导”的风险。

### 3.6 与导师四种情况的对应

| 情况 | $\Phi$ 的变化 | 工具回合得到的信用（$c=0$） | 末轮 |
|---|---|---|---|
| 原来错，用工具后对 | 上升 | 正：有效工具 | 结果信用（正） |
| 原来对，用工具后还对 | 已接近 1，基本不变 | ≈0：冗余工具不分功劳 | 结果信用 |
| 原来错，用工具后还错 | 基本不变 | ≈0：失败的探索不受统一处罚 | 结果信用（负） |
| 原来对，用工具后错 | 下降 | 负：误导性工具 | 结果信用（负） |

## 4. 类比来源（设计依据）

| 来源 | 对应 |
|---|---|
| Actor-critic 的 TD 误差 $\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$ | 中间步骤没有即时奖励、取 γ=1 时，$\delta_k=V(s_{k+1})-V(s_k)$；$\Phi$ 就是不需要训练的价值估计 |
| 势能整形（Ng et al., 1999） | $F=\gamma\Phi(s')-\Phi(s)$ 前后相消，正是“多裁不能刷分”的数学保证；对应导师说的“势能方程” |
| SAPO（本库实现：共享 LM head 读出 V/Q + turn 级 GAE，E1 .577） | VPC 可以看作把 SAPO 学出来的价值头，换成一个由强制作答概率直接给出、不需要训练的价值估计 |
| 贝叶斯实验设计 / 主动感知 | 一次观测的价值等于它带来的信息增益。可选变体：$\log\Phi$ 之差，或选项分布熵的下降（熵版不需要 gt） |
| COMA 反事实基线 | $\delta$ 本身就是与“不裁、现在作答”这个默认动作的比较；把 v53 的首动作分叉推广到每一次工具调用，且不需要额外采样 |
| Options 框架的终止优势 | 可选：$\Phi$ 已经很高时继续裁图，记为负信用，对应性能—成本权衡 |
| RUDDER 回报重分配 | 势能差是一种回报重分配，预测器换成策略模型自身的作答概率 |
| Shapley / 留一法 | 可选：每张裁图的贡献取 $\Phi(\text{全部视图})-\Phi(\text{去掉该视图})$，可以专门压制重复裁图 |
| 优先经验回放 | 3.5 的步级动态采样：按 $\lvert\delta\rvert$ 选组 |
| 导师的“逼近 + 探索 + 门控”（第 271–283 行） | $\Phi$ 不变时代表还没找到目标，可加很小的探索信号；$\Phi$ 上升后只用 $\delta$。门控由 $\Phi$ 触发，不需要标注框 |

## 5. 与已有方法的区别（待正式查新）

| 方法 | 改动位置 | 本提案的不同 |
|---|---|---|
| DAPO | 动态采样、clip-higher、token 级 loss | 保留其采样；增加步级入选条件和回合级信用 |
| Dr. GRPO / GSPO | 长度归一化、序列级比率与 clip | 预算按轨迹固定后，再按回合角色和势能分配 |
| DTPO | 中间段 / 末段分开做批次级平均（0.5 : 1） | 先固定每条轨迹的预算，再在轨迹内分配；中间回合不再平均分 |
| SAPO（V/Q + GAE） | 学出来的价值函数 | 价值估计不需要训练（强制作答概率）；n=8，可与组内比较并存 |
| VinePPO | 蒙特卡洛重采样估计中间状态的价值 | 一次前向读出概率，不需要额外 rollout |
| GiGPO | 相同状态的轨迹分组比较 | 不需要不同轨迹恰好走到相同状态 |
| RLPR / VeriFree | 以参考答案的概率作为奖励 | 以概率差分配回合信用，奖励仍是 $V\cdot Y$ |
| TACE | 保符号、保总量的信用重分配，需要额外证据对比 | 只依赖回合结构和策略自身的作答概率 |
| ZoomEye 一类 | 推理时用置信度决定是否放大 | 在训练中用于信用分配 |

## 6. 风险

- **$\Phi$ 的校准**：作答概率可能被选项先验左右，例如只看原图时就偏向 A。
- **策略在变**：$\Phi$ 由当前策略计算，训练中会漂移，“不改变最优策略”只能近似成立。
- **信号强度**：如果 $\delta$ 大多接近 0，中间回合几乎拿不到信用（$c=0$ 时等于不训练这些回合）。
- **成本**：每个状态多一次前向（带多图输入），计入训练成本报告。
- **末轮 2/3 是先验**，不是测出来的比例；DTPO 的旁证同时伴随推理成本上升。
- **4B 的上限**：这个方案不改变模型看不清的事实，只改变学习信号落在哪里。

## 7. 验证顺序

### 7.1 离线检查（不训练；DAPO step 32 的 1,191 题 × 8 轨迹，带裁图框）

1. 每次裁图前后的 $\Phi$ 与 $\delta$ 的分布；四种情况各占多少；$\delta\approx0$ 的比例。
2. 全对组和全错组中，存在 $\lvert\delta\rvert>\epsilon_\delta$ 的组数（新增信号的供给量）。
3. 独立验证：用 V\* 和 L1 框判断“真正覆盖了目标”的裁图，看它们的 $\delta$ 是否更大。框只用于检验，不进入训练。
4. $\Phi(s_0)$ 是否被选项先验左右。
5. 信用账本：同一份 rollout 下，当前 token 平均与本方案在每条轨迹、末轮、中间回合上的信用份额。

### 7.2 训练消融（同起点、同题序、n=8、同步数、同奖励、同 clip；DAPO 采样）

| 条件 | 归约与信用 | 回答的问题 |
|---|---|---|
| DAPO | 全批 token 平均 | 基线 |
| DAPO + HB | 轨迹预算固定，末轮 2/3，中间回合平均分 1/3 | 回合预算本身有没有用 |
| **DAPO + HB + VPC** | 中间回合的 1/3 按 $\delta$ 分配（$c=0$） | 势能信用在回合预算之上有没有增益 |
| （可选）+ 步级动态采样 | 3.5 | 全错 / 全对组中的 $\delta$ 信号能否带来额外收益 |

### 7.3 判据

- 只是信用分布更合理，准确率和成本都没改善：不算成功。
- 准确率略升，但推理成本明显上升（像 DTPO）：只算性能—成本上的交换。
- 同预算下准确率提高，或准确率不降而推理成本下降：继续。
- 报告时同时给出生成轨迹数、处理 token、实际时间，以及 E1 分源、裁图（首裁 / 后续）、token、截断率；按导师要求不做多 seed。
