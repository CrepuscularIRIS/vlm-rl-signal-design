# 已做与未做的方法：公式和位置

## 已运行：v53配对

(Y_i) 为严格协议门后的终答正确性，(N_i)为实际裁图数：

[
R_i=Y_i(1-0.01N_i),\quad A_i=R_i-\frac1{G-1}\sum_{j\ne i}R_j,\quad G=8.
]

control beta=0，无额外分叉。decision保留同一主目标，首动作同prefix分answer/crop-continue各4条完整续写：

[
D=\bar R_{answer}-\bar R_{crop},\quad z=\log p(t_{answer}|h)-\log p(t_{crop}|h),
\quad L_{aux}=|D|\,BCE(\mathbf1[D>0],\sigma(z)).
]

D停止梯度，beta=1/256，H0=32；完整动作标签序列概率。形式是辅助损失；RLOO control不是第二种新方法。以上两组均已完成32步及E1，没有接续冒烟权重。

代码快照见code/v53，哈希与正式启动记录核对；仅作阅读，不提供训练调度脚本。原实现mask、批次归属等必须读代码，不能只凭公式推断。

## 改动位置不可混用

| 位置 | 例子 | 当前状态 |
|---|---|---|
| 任务奖励 | 裁图成本R=Y(1−lambda N) | v53已用lambda=.01 |
| 信用分配/基线 | RLOO或按步骤分配信号 | RLOO已跑；新的步骤信用未定 |
| 辅助损失 | 首动作收益差BCE | 已跑，结果未超过control |
| 数据/采样 | DAPO动态筛选 | baseline已跑，预算另计 |

Reward shaping有时被口语用来统称“改善学习信号”；严格讨论时必须区分是否改变目标偏好、仅改变估计/归属，或增加辅助优化。势能不变性需满足折扣和终止边界等条件，不能默认覆盖任意分段PPO改法。
