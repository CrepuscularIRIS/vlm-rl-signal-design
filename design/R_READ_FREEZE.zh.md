# R-read 冻结协议：L2 读取一致性奖励 + 无过滤 GRPO（2026-11-03）

依据 [Pro 设计回复](../../../icml/papers/Design.md)（读取 Design.md `0085bd1` 后的全部追加内容）和 [感知差距简报](PERCEPTION_GAP_BRIEF.zh.md)。编号 **R-read**，不覆盖 E 系列（E=E 系列已停）。

## 冻结的奖励公式

从 L2 编译训练侧读取索引：

- 每题 1–4 个**关键读数字段** {(k_j, v*_j, N_j)}：字段名、标注真值、规范化规则
- 资格 mask m_q=1 仅当：GT 无冲突、关键值可读（无 `?`、readable=true）、规范化无歧义、属于已支持解析类型
- **不进读取分**：LC 线索层、disagree 题、需语义评审的开放描述、估读值、坐标轴推测值

### 读取分

```
commit 文本 → 抽取原始陈述及原文 span（抽取器不可见正确答案/选项）
原始陈述 + 字段名 → 匹配到任务要求的读数槽位
槽位读数 + L2 真值 → 规范化后精确匹配（τ_read=1，不做编辑距离/接近度）
```

- z_ij = 1 当且仅当：模型给出该字段的**唯一明确读数** ∧ 规范化后等于真值
- 缺失（⊥）、并列冲突值、无法确认为视觉读数 → z_ij = 0
- 选项枚举（"30, 50, 70, 80"）、否定句（"不是30而是50"只取50）、假设分支不计
- 重复不加分（每字段最多一次）
- **不写读数 = 0 分，不是免检**
- **终答错误也可获得读取分**（读对但答错时保留信号）
- 原图直答与裁图路径同一检查

Φ_read = (1/K_q) Σ_j z_ij

### 总奖励

R_i = V_i · [Y_i + 0.25 · m_q · Φ_read(q, τ_i)]

- V_i 沿用硬协议门；Y_i 沿用终答正确性
- 第一版不叠加几何分、长度分、裁图成本
- 无过滤 GRPO（保留全部组含全错全对），组内标准优势
- λ=0.25 在组内归一化下可能被抵消（已知），不能以"系数小"解释安全性

## 规范化规则（第一版冻结）

- 数字：十进制 Decimal 规则，保留负号、会计括号、百分号、数量级
- `1,234.5` vs `1.234,5`：仅在 L2 标注了地区格式时等价
- OCR 字符串：预登记的空白/编码/标点等价；大小写按任务要求决定
- 含 `?` / readable=false / 估读的字段不参与

## 离线准入（预登记，训练前必过）

### 评分器准入（300 正例 + 300 困难负例）

| 检查 | 标准 |
|---|---|
| 正例召回 | 已支持句式 ≥90% |
| 负例误给分 | 单侧 95% 上界 <2%；选项枚举/否定句/错单位不能系统性漏检 |
| 语义不变改写 | 引号/顺序/等价空白不影响分数 |
| 内容变化 | 数字/符号/单位/对象真正改变时分数按预期变化 |
| `?`/缺失/不可核验 | 不判为读对；不额外奖励"说不清楚" |

### 成对反例（必须在已有 E1 轨迹上验证）

| 对照 | 预期 |
|---|---|
| 正确转录→改错一个关键字符 | 该字段分 1→0 |
| 正确读数→"选项里有 30、50、70、80" | 不因包含真值得分 |
| "不是 30，而是 50" | 只取 50 |
| 正确价格→同数值错误货币/百分比 | 单位影响含义时不得分 |
| 同一读数重复三次 | 分数不增加 |
| 原图读对→加一次无关裁图 | 读取分不变 |
| 终答字母不变，caption 错读数改对 | 读取分变化（区别于 Y） |
| 读数相同但换成另一对象/列 | 不得判为该字段正确 |

### 信号准入

| 统计量 | 定义 | 准入线 |
|---|---|---|
| ν_allwrong | P(Var[Φ_read]>0 \| 全错组, m_q=1) | — |
| ν_allcorrect | 同上全对组 | — |
| ν_fixedview | P(0<Σz_ij<8 \| 同字段同视图同输入) | — |
| **有效读取差异率** | 适用且终答无差异的组中，≥10% 提供经审核差异 → 完整训练；<5% → 暂停检查；5–10% → 有限预算探索 | 10% / 5% |

需同时报告：m=1 覆盖率、明确写出读数的比例、解析成功率、人工核验读数正确率。

## 训练矩阵（Pro 版 G 系列，先跑第一列）

| 编号 | 起点 | 奖励 | 作用 |
|---|---|---|---|
| **G0** | 4B A-SFT | V·Y 纯终答 | 参照（k8 GRPO .6390 可复用） |
| **G1 (R-read)** | 同上 | V·[Y+0.25·m·Φ_read] | **主实验** |
| G2 | 同上 | G1 + 同观测局部 GRPO | 后置 |
| G3 | 同上 | G2 + 可验证操作课程 | 后置 |

- 所有训练：32 步、128×8、无过滤 GRPO、clip .2/.3、lr 1e-6、seed 42
- G2 的同观测分组：从真实到达状态 (q,h_t,O_≤t,b_t) 分叉 8 条后续，loss = 0.75·L_full + 0.25·L_local
- G3 的课程：同图分层（局部读取→有干扰读取→多事实组合→完整任务），不提供标准轨迹

## 推翻条件（预登记）

| 结果 | 支持的判断 | 不能推出 |
|---|---|---|
| 固定视图 4B 极少正确读取 + R-read 无有效组差异 | 当前 on-policy exact-reading RL 缺少可利用支持 | 4B 绝对感知上限 |
| 有可靠读取方差 + 过程梯度进更新 + 独立读取测试不改善 | 此奖励/更新方式未有效转化 | 所有失败由感知决定 |
| 训练读取分↑ + 去选项固定视图读取不↑ | 表达适配/选项复制/评分器投机 | 感知能力提高 |
| 固定视图读取↑ + 端到端不↑ | 读取改善未转化或被搜索/推理回归抵消 | 读取奖励无效 |
| 终答↑ + 读取诊断不改善 + 搜索行为改变 | 收益来自搜索/策略变化 | 感知学习 |

效应门槛：独立读取字段正确率 ≥+3pp，总体准确率 ≥+1pp，按源图族配对置信区间。

## Hacking 防线

| 攻击 | 防线 |
|---|---|
| 不写值逃避检查 | 固定字段分母；缺失=0 |
| 抄所有选项进 caption | 只接受唯一肯定陈述；枚举不计 |
| 碰巧复制正确选项声称"看到了" | 不从答案回填；独立去选项读取评测 |
| 抄一个易字段漏关键字段 | 只对预定的决定性字段计分 |
| 重复事实/裁图刷分 | 每字段最多一次，终局评分 |
| 正确数字绑到错误对象 | 最小身份检查；同值候选冲突入绑定消融 |
| 标点规范化抹掉负号/单位 | 字段级 Decimal 规范化 |
| L2 evidence_summary 泄露进 actor 输入 | reward-only sidecar；actor prompt 与基线逐字段核验 |

## 独立评测（不进训练，训练后测）

1. **固定视图去选项读取**：给训练前后完全相同视图，无选项，要求读出字段值
2. **相关内容变化测试**：同类型不同图/不同数值/相似布局，模型应随内容改变读数
3. 按源图族隔离，不能只换 UID
4. 同时报"每要求字段正确率"和"已陈述字段中的正确率"
