# 过程信号的构造：必须满足的条件与可借鉴的方法菜单（2026-11-05）

用途：在设计“把过程信号放进 advantage”的算法之前，先把构造必须满足的条件和可选方法列出来，与势能方程并列作为候选。配套任务书：[prompts/ASTRA_ADVANTAGE_DESIGN_20261105.md](../prompts/ASTRA_ADVANTAGE_DESIGN_20261105.md)。

## 一、任何构造都要先回答的十个问题（来自我们已测到的问题）

| # | 问题 | 为什么要问（我们的测量） |
|---|---|---|
| 1 | 信号**测的是什么**：取证（看没看到）、读取（读没读对）、绑定（对没对上行列）、推理，还是写法？ | RL 之后组内对错差异的多数在“看到之后”（V\* 上 DAPO 53%）；Φ_bind、轻量版 L2 的信号主要测到写法（47%） |
| 2 | 在**同题、同结果**的兄弟之间，它有没有差异？ | 跨题差异（例如探针 b0：答对 .436 vs 答错 .195）只是题目难度；组内 AUC 才有用，目前都只有 .53–.61 |
| 3 | 是**因果**（干预后结果会变）还是**相关**（同时出现）？ | 几何覆盖与对错相关，但覆盖了仍会读错（vstar_15） |
| 4 | **覆盖率与精度**：多少题、多少轨迹能拿到非 ⊥ 的标签；判 0 和判 1 的精度各是多少？ | L2 成对比较精度高（29/30、30/30），但 P≠0 只有 2.3% |
| 5 | 进入 advantage 后，**组内零和**、**正负质量比**、**正负号**是否保持？ | DAPO-SB 正负比 2.23，entropy 下降；减组均值的方法在 .91–.97 |
| 6 | **全对 / 全错组**怎么处理？ | 加进 reward 再整组 z-score 后，这类组占 28% 的 advantage 质量 |
| 7 | 信用给**哪个回合、哪些 token**？ | 生成 token 以思考文本为主；最终回合约占 30%；bbox 坐标和答案字母只占极少数 |
| 8 | 在**每步都被裁到 1.0、clip 从不触发**时，它改变的是方向还是只改尺度？ | 只改尺度的改动没有作用 |
| 9 | 额外成本：多几次前向、要不要额外 rollout？ | 一次无梯度前向约占每步时间的 10%（old 150 s / step 1,491 s） |
| 10 | 标签本身的噪声：不可答题、GT 有误、标注漏标 | DAPO 更新组中 23% 来自 L0 不可答或 GT 有问题的题 |

## 二、方法菜单

按它回答的问题分成五类。“落地”一列只写在我们的设置里怎么做，不代表已经验证。

### A. 状态价值：这个状态离答对还有多远（势能本身怎么定义）

| 方法 | 出处领域 | 核心做法 | 在我们这里怎样落地 | 成本 / 风险 |
|---|---|---|---|---|
| A1 势函数 shaping | RL 理论（Ng 1999 potential-based shaping，TD / GAE） | 用状态势 Φ(s) 的差分作为每步的附加信用；终止势清零时不改变最优策略 | Φ = 导师的逼近 / 探索（L1 几何），或下面任何一种状态价值 | 0 前向；几何势单调不降，表达不了“变差”；Ng 形式在期望上不改变偏好 |
| A2 强制作答探针 | 早停 / anytime prediction；我们的 DAPO-SB | 在每回合之前只给已看到的视图，强制作答，读 P(gt) | 已有实现（`stop_baseline.py`） | 每个不同状态 2 次单 token 前向；不能直接当基线替换组均值（DAPO-SB 的教训） |
| A3 蒙特卡洛续写价值 | VinePPO、Math-Shepherd（用续写成功率自动生成过程标签）、MCTS | 从某个中间状态续写 k 条，成功率作为该状态的价值 | 在裁图边界保存状态，续写到终答 | 每个状态 k 条 rollout，成本最高；方差大 |
| A4 信息增益 | 贝叶斯实验设计（Lindley 1956）、主动感知 / 主动视觉 | 一次观察的价值 = 答案分布熵的下降 | 用探针读全部选项的分布，算 H 的变化，而不是只看 P(gt) | 与 A2 同成本；高信息增益不等于朝正确方向 |
| A5 线性探针 | 可解释性（probing classifier） | 用隐藏状态训练一个小分类器，预测“目标是否已被看清 / 读对” | 用 L1 / L2 标签离线训练探针，训练中复用 actor 前向的隐藏状态 | 几乎 0 额外前向；需要离线训练，并提防分布漂移 |

### B. 步骤归因：这一步（这次裁图）改变了什么

| 方法 | 出处领域 | 核心做法 | 在我们这里怎样落地 | 成本 / 风险 |
|---|---|---|---|---|
| B1 反事实基线 / 差分奖励 | 多智能体 RL（COMA 的反事实基线；Wolpert & Tumer 的 difference rewards） | 某个动作的信用 = 实际结果 − 把这个动作换成其他动作后的期望结果 | 把第 k 次裁图换成同状态下的其他候选（L1 目标框、随机框、平移框），再用 A2 / A3 评估 | 需要替换后的探针或续写；候选动作集合怎么取是关键 |
| B2 遮挡 / 消融 | XAI（Zeiler & Fergus 遮挡分析；RISE）；VPPO / PAPO 的遮挡前向 | 去掉第 k 张裁图的回执视图，teacher-forcing 重算最终答案的概率，下降量即这张图的贡献 | 每张裁图一次无梯度前向（或一次前向同时遮多张、分组估计） | 最多 8 张图时为 K 次前向；遮挡后的上下文分布外 |
| B3 Shapley 值 | 合作博弈；数据归因（Data Shapley） | 一个元素的贡献 = 在所有子集上的平均边际贡献 | 把一条轨迹的几张视图当作玩家，用少量随机排列近似 | 前向次数随排列数增加；比 B2 更公平地处理冗余视图（对应导师“冗余工具不分功劳”） |
| B4 同状态分叉配对 | 偏好学习（DPO）、Tree-GRPO、ARPO；我们 v53 的首动作分叉 | 共享前缀，只在一个决策点分叉，续写到终答，比较两支的结果 | 在裁图边界分叉“继续裁”与“现在作答”，或分叉不同的框 | 额外 rollout；我们已有 v53 的分叉实现 |
| B5 注意力 / 归因分数 | 机制可解释性（causal tracing、attention rollout） | 作答 token 对各视图 token 的注意力或梯度归因 | 复用 actor 前向，不需要额外前向 | 相关性，不是因果；与 B2 对照校准后再用 |

### C. 结果归因：答案是不是建立在正确的读数上（L2 的用法）

| 方法 | 出处领域 | 核心做法 | 在我们这里怎样落地 | 成本 / 风险 |
|---|---|---|---|---|
| C1 **反事实事实替换**（因果中介分析） | 因果中介分析（Vig et al. 2020）；反事实数据增强（Kaushik et al. 2020，“learning the difference that makes a difference”） | 在轨迹文本里把模型写出的读数换成 L2 的易混淆值（distinguishing_condition 的负例），重算答案概率；答案随之改变，说明答案确实依赖这个读数 | 只需在文本中定位数值字符串，不必判断“行列是否写全”；正标签 = 写了真值且答案依赖它；负标签 = 写了错值且答案依赖它 | 每个事实一次无梯度前向；能避开轻量版的“写法”问题（47%）中的一部分；仍需要在文本里找到数值 |
| C2 视觉反事实（把证据区域涂掉） | 反事实视觉解释；PAPO / CFPO 的遮挡 | 只遮掉 L1 目标框对应的像素（而不是整张视图），重算答案概率 | L1 框在原图坐标上，映射到各个视图后遮挡 | 一次前向；区分“答案依赖目标区域”与“依赖其他区域或语言先验”；与 D0 中“原图已足够 34%”的情况相关 |
| C3 事后重标（hindsight relabeling） | 机器人学（HER，Andrychowicz 2017） | 失败的轨迹按“实际达成的子目标”重新标为成功 | 答错的轨迹若读对了某个 L2 事实，把“读对该事实”记为子目标成功，在答错层内给小正信用 | 0 前向；对应导师“必要但失败的探索不统一处罚” |
| C4 最小对比对 | NLP 最小对（minimal pairs）、对比学习 | 构造只差一处的两个输入，看模型输出是否随之变化 | 同一题，原图与“目标区域换成干扰值”的合成图（需要图像编辑） | 需要图像编辑，成本高；可以先只在文本层做 C1 |

### D. 标签来源与去噪：标签从哪来、错了怎么办

| 方法 | 出处领域 | 核心做法 | 在我们这里怎样落地 |
|---|---|---|---|
| D1 人工 / 模型标注 | 监督学习 | 直接用 L1 / L2 / LC | 已有：L1 3,559 题、L2 3,255 题 |
| D2 兄弟一致性（伪标签） | 自训练、多数投票、在线标签修正（OLR） | 同题 8 条轨迹对同一事实的多数读数作为伪真值 | 在 E1 这类没有 L2 的题上也能用；多数错时会放大错误 |
| D3 噪声鲁棒训练 | 噪声标签学习（co-teaching、small-loss） | 对可能有噪声的样本降权 | 对 L0 不可答 / GT 有问题的题（占 DAPO 更新组 23%）降权或排除 |
| D4 从标注蒸馏小评分器 | PRM（过程奖励模型）、Math-Shepherd | 用 L1 / L2 训练一个小模型，给轨迹步骤打分 | 能替代脆弱的规则抽取（47% 漏识别）；需要额外训练与校准 |

### E. 信号怎样进入 advantage（与构造方法正交，任选组合）

| 写法 | 出处 | 性质 | 我们的状态 |
|---|---|---|---|
| E1 同结果层内中心化：A = z(Y) + λ(Q − 同层均值) | Stratified GRPO（按结构分层）、HDPO（只在答对轨迹之间比较效率） | 层内零和；混合组正负号保持；全对 / 全错组得到小信号 | 正在训练（sgv3） |
| E2 乘性重分配：A = A^Y + λ\|A^Y\|P | 本组构造 | 全对 / 全错组为 0；改变量不超过 λ\|A^Y\| | 已实现（sgv4，未开训） |
| E3 按信用份额在回合间分配 | 本组席 A 的 PC | 只收缩、不放大，每组正负比保持 | 推导完成，未实现 |
| E4 分别归一后合并 | GDPO | 每个信号各自在组内标准化再相加 | 未实现；会除以各信号自己的标准差 |
| E5 换基线 | DAPO-SB、TRACE | 期望梯度不变，只改方差 | **DAPO-SB 失败**：基线不是组内零和 |
| E6 回合 / 段权重 | DTPO、80/20、VPPO 的 token 掩码 | 只改相对权重 | DTPO 在 GRPO 上 +1.63，区间含 0 |

## 三、几个值得优先考虑的组合（只作提议，供设计时选择）

1. **C1 + E1 / E2**：用 L2 的易混淆值做反事实事实替换，得到“答案是否依赖正确读数”的标签，在同结果层内比较。它直接对准“看到之后读对 / 读错”这类多数差异，也绕开了“必须把行列写全”这个导致漏识别的条件。
2. **B2 或 B3 + E3**：用遮挡或 Shapley 估计每次裁图对答案的贡献，作为回合间的信用份额。它对准导师的“冗余工具不分功劳、误导工具承担责任”，因为遮挡能表达“去掉这张图答案反而变好”。
3. **A1 + C3**：几何势（逼近 / 探索）负责取证阶段；在答错的轨迹里，读对了 L2 事实的事后视为子目标成功。这样导师的“必要但失败的探索不统一处罚”就有了具体落点。
4. **D3 作为所有组合的前置**：对 L0 不可答、GT 有问题的题降权或排除。这一项不依赖任何新信号。
