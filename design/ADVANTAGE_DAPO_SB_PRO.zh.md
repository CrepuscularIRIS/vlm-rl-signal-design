可以按这条思路推导。但我建议调整第一版的落点：

**不先完整跑我上一轮的 HB-GRPO，也不直接启动现在这个“工具回合只吃相邻势能差”的 VPC。先做一个更保守、推导更完整的候选：DAPO-SB，停止反事实基线。**

它仍然使用你提出的视觉概率探针，但不直接奖励“探针概率涨了多少”，而是：

\[
\boxed{
\text{这一轮的信用}
=
\text{这条分支最终实际有没有答对}
-
\text{在这一轮之前，直接作答有多大概率答对}
}
\]

这个设计可以从导师的四种情况直接推出来，也能与 VPC、TD 和 GAE 统一起来。最重要的是：**它把模型概率放在 baseline 的位置，而不是先把它当成真实工具价值。**

下面给出完整设计、与原 VPC 的关系，以及实验顺序。

## 一、先明确两件事：研究目标与已有工作

按你补充的要求，DAPO 动态补采应完整保留。过滤零方差组、补采有学习信号的组，本来就是它的方法组成，不应称为“不公平”。后续报告实际计算成本即可，不必把“等生成量对照”作为立项前提。DAPO 原论文也是把动态采样作为独立核心组件。[arXiv](https://arxiv.org/html/2503.14476v2)

我上一轮提出的 HB-GRPO，只改变不同轨迹、不同阶段的权重，**不能识别某次工具使用是否改变了答对前景**。它适合做归约消融，不应该继续作为满足导师四种信用方向的主方案。

另外，查新有一个重要发现：**TRACE 已经非常接近你提出的 VPC。** 它在工具调用边界，用冻结参考模型的正确答案概率构造状态值，再计算 TD 差分，并做多步传播、与 GRPO 结果优势结合。因此，“不训练 critic，用正确答案概率做势能差”本身不能直接当成新贡献。你们需要证明的，应是具体的状态定义、优势构造和视觉工具任务中的效果，而不是重新命名这个结构。[arXiv](https://arxiv.org/html/2607.13988v1)

这不意味着不能做。它意味着应当把设计放在已有方法的基础上，避免再次从一个漂亮类比直接跳到开训。

## 二、原 VPC 有三个关键缺口，需要先补上

### 1. “现在直接答对的概率”不等于“继续执行策略最终答对的概率”

你定义的量更准确地应写成：

\[
\Phi(h)=P_{\pi_{\rm probe}}
\big(\text{现在停止搜索并直接答对}\mid h\big).
\]

而标准价值函数是：

\[
V^\pi(h)=P_{\pi}
\big(\text{从这里继续运行，最终答对}\mid h\big).
\]

二者可能差很大。

例如，第一次裁图只是找到了“目标在右上区域”的线索，尚不足以回答颜色问题。此时直接作答成功率可能没有提高，但它使下一次有效裁图成为可能。

所以：

\[
\Delta\Phi\approx0
\]

**不等于这次探索没有价值。**

VinePPO 使用完整续写的回报估计中间价值，恰恰是在估计后一种“继续执行的价值”，不是立即作答的概率。[arXiv](https://arxiv.org/abs/2410.01679)

### 2. 四种离散结果，不自动对应四种概率变化

“前后都答错”可能对应正确选项概率从 \(0.05\) 上升到 \(0.35\)；“前后都答对”也可能对应从 \(0.55\) 上升到 \(0.95\)。

因此，你的四格表可以作为**期望的信用方向**，不能作为 \(\Delta\Phi\) 必然满足的性质。

尤其不能把一次直接回答正确，就当成 \(\Phi\approx1\)。这需要重复测量与校准。

### 3. 势能相消，不等于实际梯度不会被利用

工具步骤满足：

\[
\sum_{k=0}^{K-1}
\big[\Phi(h_{k+1})-\Phi(h_k)\big]
=
\Phi(h_K)-\Phi(h_0).
\]

这个代数等式正确，但还没有包含最终作答的校正。如果终止状态势能设为零，最后一步应当包含：

\[
Y-\Phi(h_K).
\]

完整相加才得到：

\[
\sum_{k=0}^{K-1}\Delta\Phi_k
+
\big[Y-\Phi(h_K)\big]
=
Y-\Phi(h_0).
\]

Ng 等人的势能整形理论针对的是满足相应条件的完整奖励变换，不是任意把局部差分塞进工具 token、再给终答另一套优势，就能继承“不改变最优策略”的结论。[People @ EECS](https://people.eecs.berkeley.edu/~russell/papers/icml99-shaping.pdf)

还要区分信用数值与梯度。即使两个步骤的信用是 \(+0.2,-0.2\)，也不意味着：

\[
0.2\nabla\log\pi(a_1\mid h_1)
-
0.2\nabla\log\pi(a_2\mid h_2)=0.
\]

不同 token 的梯度方向、重要性比率和裁剪状态不同。**“数值相消”不足以证明“多裁图在优化中无法获利”。**

## 三、从导师的四种情况反推：先比较“继续这条分支”与“现在就答”

这里不先找一个会涨的过程指标，而是先确定比较对象。

在第 \(k\) 轮开始之前，模型处于历史状态 \(h_{i,k}\)。定义：

\[
b_{i,k}
=
P_{\pi_{\rm probe}}
\big(y^\star\mid
q,\text{截至此时实际看过的视图},
\text{强制直接作答}\big).
\]

令 \(Y_i\in\{0,1\}\) 为这条实际轨迹的原始合法终答奖励。

那么一个直接的、相对停止行为的信用估计是：

\[
\boxed{
C_{i,k}=Y_i-b_{i,k}.
}
\]

注意比较的是：

> **从当前状态出发，这次实际选择及后续分支的结果，相比现在停止作答，好了多少。**

它不是声称单独识别了当前裁图的全部因果贡献。

### 四种情况怎样出现？

下面用 \(0.05\) 和 \(0.95\) 表示“直接作答成功率很低”和“很高”。这是构造例子，不是实测值。

| 当前直接作答的前景 | 实际继续后的结果 \(Y\) | \(Y-b\) | 信用方向 |
|---|---:|---:|---|
| 很难答对，\(b=0.05\) | 答对，1 | \(+0.95\) | 大幅强化成功分支 |
| 已经能答，\(b=0.95\) | 仍答对，1 | \(+0.05\) | 不再因为答对就给大量额外功劳 |
| 很难答对，\(b=0.05\) | 仍答错，0 | \(-0.05\) | 失败探索只受较小惩罚 |
| 已经能答，\(b=0.95\) | 反而答错，0 | \(-0.95\) | 强烈抑制把局面弄坏的分支 |

**这张表与导师的要求对应，而且不需要假定“所有有效探索都必须立即提高作答概率”。**

它保留了一个保守限制：答错轨迹中的工具步骤不会因此获得正信用，但可以避免和“已有充分信息后仍然答错”受到一样的惩罚。要给失败轨迹中的某些步骤正信用，就需要进一步相信局部价值估计，不能免费得到。

### 一个更贴近你们任务的例子

假设某条轨迹各轮开始前的直接作答概率是：

\[
b=(0.1,\ 0.1,\ 0.9,\ 0.9).
\]

可以理解为：第一轮探索尚未使问题可直接回答；第二轮找到了关键证据；第三轮继续裁图；第四轮提交答案。

若最终答对，则各轮原始信用为：

\[
C=(0.9,\ 0.9,\ 0.1,\ 0.1).
\]

若最终答错，则变成：

\[
C=(-0.1,\ -0.1,\ -0.9,\ -0.9).
\]

这体现了一个很具体的变化：

**失败时，不再把尚未取得信息的早期探索，与已经取得信息之后的错误操作和错误提交，统一施加同样的负优势。**

但它也有明确局限：在取得证据之前，一个其实无用的步骤，可能因为后续其他步骤成功而获得信用。因此它是**相对停止的分支信用**，还不是每张裁图的独立边际贡献。

这条界限必须写在方案里，不能用“反事实”三个字掩盖。

## 四、完整算法：DAPO-SB，只替换优势估计

### 1. 保留原有采样、奖励与优化器

第一版保留你们已有的 DAPO 设置：同题生成 8 条轨迹，动态补采混合组；奖励仍为原始合法终答的 0/1 判定；重要性比率、clip、dual clip、学习率和 loss 归约都不改。仓库现有 DAPO/SP/CA 记录明确了这些接线位置。

不要同时加入成本奖励、末轮 \(2/3\) 权重、序列级 ratio 或新的题目重采样策略。否则无法知道收益来自哪里。

### 2. 把题组共同 baseline 换成每轮的停止 baseline

当前 DAPO 优势为：

\[
A^{\rm DAPO}_{q,i}
=
\frac{Y_{q,i}-\bar Y_q}{\sigma_q+\epsilon}.
\]

提出的第一版改为：

\[
\boxed{
A^{\rm SB}_{q,i,t}
=
\frac{Y_{q,i}-b_{q,i,k(t)}}{\sigma_q+\epsilon}.
}
\]

其中，\(k(t)\) 表示 token \(t\) 所属的 assistant 回合，\(\sigma_q\) 继续使用当前代码的组内奖励样本标准差。

这个修改的实质是：

> DAPO 问：“这条轨迹比同题其他轨迹好多少？”  
> DAPO-SB 问：“从这一轮开始，实际结果比现在直接回答好多少？”

**工具回合和最终作答回合都采用这一规则。** 不再给工具用一种价值定义、给终答留下另一套互不对应的定义。

对于 8 条轨迹的二元混合组，样本标准差至少为 \(1/\sqrt8\)。由于 \(Y-b\in[-1,1]\)，忽略稳定项时：

\[
|A^{\rm SB}|\le \sqrt8.
\]

因此第一版不需要额外引入一个用于放大局部概率差的 \(\beta\)，也不需要除以很小的局部 \(\operatorname{std}(\delta)\)。

### 3. 信用必须赋给真实生成的整个 assistant 回合

一轮中的描述、思考和动作输出，使用同一个回合优势；工具回执、图片输入、探针输入全部不参与 policy loss。

特别重要的是，\(b_{i,k}\) 必须在**该轮生成之前**确定。不能把当前轮已经输出的答案、裁图框或文字放进这个 baseline，再把它用于训练同一轮。

回合边界来自真实 rollout 记录，不从模型写的 `Step 3` 等文本猜测。非法或截断轨迹依然保留，按原协议得到 \(Y=0\)。

### 4. 为什么这个位置比“直接把概率差当工具价值”保守？

在未筛选的 on-policy 策略梯度中，任何不依赖当前动作的 baseline 都满足：

\[
\mathbb E_{a\sim\pi(\cdot\mid h)}
\left[
b(h)\nabla_\theta\log\pi_\theta(a\mid h)
\right]
=
b(h)\nabla_\theta\sum_a\pi_\theta(a\mid h)
=
0.
\]

因此，**作为 baseline，\(b(h)\) 不必精确等于真实价值函数，才有这个零期望性质。** 作为 TD bootstrap 的下一状态价值，要求则更强。GAE 的分析明确区分了这两种用途。[arXiv](https://arxiv.org/html/1506.02438v6)

但不能进一步声称“本算法因此严格无偏”。实际版本保留了 DAPO 的结果筛选、样本标准差归一化和 PPO 裁剪，上面的完整条件已经改变。

准确说法应当是：

**基础构造来自合法的状态 baseline；实际 DAPO-SB 是需要实验检验的 clipped、group-scaled surrogate，而不是带有无条件无偏保证的新定理。**

而且 baseline 选得不好，仍可能增大梯度方差。经典研究并不支持“任何更细的 baseline 都一定更好”。[Journal of Machine Learning Research](https://www.jmlr.org/papers/v5/greensmith04a.html?utm_source=chatgpt.com)

## 五、这不是绕开你的势能思路，而是它的完整回报端点

把工具步骤和最终作答统一起来：

\[
\delta_{i,k}=
\begin{cases}
b_{i,k+1}-b_{i,k},&k<K_i,\\[3pt]
Y_i-b_{i,K_i},&k=K_i.
\end{cases}
\]

其中 \(K_i\) 是最终作答或终止回合的索引，终止后的势能为零。

再定义：

\[
\boxed{
A^{(\lambda)}_{q,i,k}
=
\frac{1}{\sigma_q+\epsilon}
\sum_{\ell=k}^{K_i}
\lambda^{\ell-k}\delta_{i,\ell},
\qquad \gamma=1.
}
\]

现在得到一条清晰的方法谱系：

**当 \(\lambda=0\)**，工具回合使用相邻势能差，最终回合使用 \(Y-b_{\rm final}\)。这是补上终答校正后的局部 VPC。

**当 \(\lambda=1\)**，所有中间项相消：

\[
A^{(1)}_{q,i,k}
=
\frac{Y_i-b_{i,k}}{\sigma_q+\epsilon}.
\]

这就是上面的 DAPO-SB。

**当 \(0<\lambda<1\)**，未来的信息增益和终答残差部分向前传播。这是两者之间的折中；如果 \(b\) 不是继续执行策略的准确价值，便存在 bootstrap 偏差。这个关系正是 GAE 的基本结构。[arXiv](https://arxiv.org/html/1506.02438v6)

这让下一步不必不断发明新模块：

> **共用同一个视觉概率探针，只比较“多信任真实终答”与“多信任局部概率变化”的区别。**

我建议第一版把 **\(\lambda=1\)** 作为主候选，而不是因为经典公式里常出现某个数，就直接使用 \(\lambda=0.95\) 或 \(0.5\)。

原因是你们当前最不确定的恰恰是探针是否可信。先把它放在 baseline 位置，比立即让它替代工具分支的真实回报更稳妥。之后若独立验证支持局部变化，再测试较小的 \(\lambda\)。

这也说明，与 SAPO 的关系不能简单描述为“把学习到的价值头换成一个现成准确的价值头”。你们使用的那类 SAPO 在学习状态/动作价值并做 turn-level GAE；这里的直接作答概率首先是一个参考 baseline，并未自动获得相同的价值语义。[arXiv](https://arxiv.org/abs/2608.19842)

## 六、视觉概率探针怎么实现，才能避免新的测量问题？

我同意保留“题面＋实际看过的视图，不放模型自己的思考文本”作为首版探针输入。不过应称为**规范化直答参考策略**：它不是原多轮策略在完整历史上选择停止的精确概率。

具体接口需要冻结以下约定。

**图像与上下文。** 只输入该状态之前模型实际获得的图像，保持实际呈现分辨率。不能把模型当时没看到的高清原图交给探针。保留题目、全部选项，以及必要的中性视图定位信息；不输入当前轮生成内容。正确答案只用于选取对应输出概率，不出现在提示词中。

**选项概率。** 检查候选字母在所用 tokenizer 和回答前缀下是否确实都是单 token。满足时可从一次前向的全部候选 logits 得到受限选项分布；不满足时需计算完整候选字符串概率，不能硬取“第一个字母 token”。同时记录原词表上有效选项的概率质量，避免把“基本不会按要求作答”归一化成一个看似很自信的选项分布。

**冻结方式。** 同一 rollout batch 使用同一份行为策略快照计算所有 \(b\)，保存后停止梯度。该 batch 的多个 optimizer update 期间不重算。下一批再更新探针快照，避免一条轨迹内部使用不同模型评分。

**计算成本。** 没有额外续写采样，不等于几乎没有成本。每个状态仍需要处理题面和已有图像。在初始状态可共享、且精确缓存相同状态的情况下，一个题组所需的状态打分数约为：

\[
N_\Phi=1+\sum_{i=1}^{G}K_i,
\]

这里 \(K_i\) 是第 \(i\) 条轨迹的裁图次数。成本应实测，不能仅凭“只读一个输出 token”估计。

第一版只给 DAPO 已保留的组打分即可，先不要把所有筛掉的组也引入训练。

## 七、离线验收应当改成“探针—信用—真实更新”三层

你提出的覆盖率、信号供给量和选项先验检查都值得保留，但不足以单独决定开训。尤其是“覆盖目标后 \(\delta\) 更大”，仍可能只是另一个相关性结果。

### 第一层：探针究竟测到了什么？

在训练题上抽取一批真实 pre-turn 状态，检查：

一方面，重排选项字母、替换无关裁图、重复已有裁图时，概率是否发生不合理变化。另一方面，从同一真实历史出发，按实际回答协议禁止继续用工具、直接完成作答，比较这类真实停止行为与规范化探针的预测。

**不要用同一个探针分布采样字母，再检查其命中率是否等于探针概率。那基本只是在验证概率定义，不是在验证它能代表实际作答能力。**

还应同时检查训练起点和后期 checkpoint。只验证 step 32 上的探针，不能证明它在刚开始训练时也可用。

### 第二层：四种信用方向是否真的被识别？

四种情况需要同状态的比较，不能仅按原轨迹最终对错分类。

在一个受控小样本上，分别观察“现在停止作答”与“执行工具后继续”的结果分布，并保留真实剩余轮次与上下文预算。这可以复用你们已有的分叉基础设施，只用于离线验证，不立即变成每步训练的额外采样。仓库的 SP/CA 已经包含同状态续写和预算继承的实现经验。

然后分别检查：

- 原本难以直接作答但最终成功的分支，是否获得更强正信用；
- 已经可以直接回答却最终失败的分支，是否受到更强负信用；
- 失败轨迹早期的低可答状态，是否不再与后期高可答状态受到同样惩罚。

这些才是当前候选实际承诺的性质。是否识别了“单张裁图的独立贡献”，应另列为尚未解决的问题。

### 第三层：改变的是更新，还是只改变了表格？

固定同一份模型、rollout 和 optimizer 状态，至少计算三套优势：

| 条件 | baseline | 检验目的 |
|---|---|---|
| 原 DAPO | 同题组均值 \(\bar Y_q\) | 当前基线 |
| 根状态基线 | 整条轨迹固定使用 \(b(h_0)\) | 排除“只是换了共同 baseline” |
| DAPO-SB | 每轮使用 \(b(h_k)\) | 检验状态相关信用是否有额外作用 |

比较真实梯度方向、跨批次波动、裁剪后的梯度和一次 optimizer update 的参数变化。不要只比较 advantage 方差或裁剪前范数。

**如果动态状态基线不比固定根状态基线好，就不能把后续任何增益归因于更细的时间信用分配。**

离线阶段还可以同时计算 \(\lambda=0\) 和 \(0.5\)，但先不为每个取值各跑一轮完整训练。

### 正式训练顺序

第一对实验就是：

\[
\text{纯 DAPO}
\quad\text{对比}\quad
\text{DAPO-SB}.
\]

保留 DAPO 的动态采样，不要求人为消除它的补采优势。记录准确率、推理成本、训练额外前向成本，以及重复裁图和截断行为。

有收益后，再做固定根状态基线的消融，判断收益是否真的来自逐轮状态变化；随后才决定是否测试局部 VPC/中间 \(\lambda\)。

**不要第一轮就同时修改优势和入组规则。**

还有一个数据口径要纠正：4,096 题中有 2,648 题进入 DAPO 更新，未进入的 1,448 题不等于“1,448 道难题”。全对题也会被筛掉，仓库统计明确区分了全对、全错和混合组。

因此，“恢复未更新题的学习”应另做难度与信号审计，不能仅凭 \(\delta\) 有方差就把这些题全部接回训练。**噪声也有方差。**

## 八、你列出的其他类比，哪些值得借，哪些暂时不要加？

最值得借的是**状态 baseline、终答残差和多步信用传播**。它们已经被统一在上面的算法族里，不需要再拼接多个模块。

COMA 可以借鉴“与参考选择比较”的思想，但 COMA 的原始基线是对某个智能体动作做边缘化，不是任意两个前后状态的概率差。这里使用“现在直接回答”作为默认参考行为，应明确这是你们的设计选择，而不是直接复现了 COMA。[AAAI Open Access Journal](https://ojs.aaai.org/index.php/AAAI/article/view/11794)

熵下降不适合作为第一版信用信号。模型从犹豫变成自信地答错，熵同样下降。普通留一删除也不能直接称为 Shapley：两个相互替代的重复视图，留一删除可能都得到零，但 Shapley 会在不同加入顺序之间分配贡献。二者回答的是不同问题。

“势能高就惩罚继续裁图”也应暂缓。势能高并不能证明下一次观察没有增益；要严格优化性能—成本权衡，还需要明确的成本目标或约束。**在奖励和目标完全不包含成本时，不能同时承诺算法必然学会最少裁图。**
