# 下一次建模讨论的起点

目标是基于当前证据提出简单、有区分力的建模思路，不是给已有解释找包装。

1. 先说哪些差异已经在同题对照中观察到，哪些只是总分相近掩盖的题目变化；将来源、正确次数、过程证据分别列。
2. 当前最值得讨论的信号缺口是什么？请在覆盖、目标信息、步骤归属、基础感知/推理能力、接口执行中保留竞争解释，允许结论“当前不足以选”。
3. 如果从advantage/credit assignment切入，究竟估计什么量、用到哪些信息、在哪个状态/分组内比较、分给哪些token？公式只定义可获得的量；若需gold或额外rollout，明确成本。
4. 不先设计一堆奖励。最多提出两个简单候选，分别说明事实依据、最近邻机制、必要假设、全错/全对/重复证据/正确但依据错/裁对但答错时如何处理，以及哪种结果会否定该设计。
5. 给出最小可区分测试草案；不自动更改现有协议、SFT、评分器、标签或启动训练。预算/精度容忍delta未定，不代研究者选择。

拒答、幻觉惩罚、reward shaping可以保留为后续方向；当前先理解成败与学习信号。公开证据里没有图像、没有E1→训练梯度逐条映射，不能用模型自述补造。所有候选均须经用户决定后才可能执行。
