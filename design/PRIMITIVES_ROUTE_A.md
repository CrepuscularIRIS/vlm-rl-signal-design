# Primitives 的理解与 A 路线方案（2026-11-01）

承接 [VISUAL_PRIMITIVES_BRIDGE](VISUAL_PRIMITIVES_BRIDGE.md) 和 [HINTS_AS_REWARD](HINTS_AS_REWARD.md)，本文记录 10-31 至 11-01 讨论后的最新方案。**研究者已选定 A 路线**：保留现有 A-SFT，只在 RL 阶段加入过程信号。

本文性质：§2–§3 是实测事实；§1、§4–§7 是研究者的决定和讨论稿；§8 记录进度。没有新的训练实验。

---

## 1. 研究问题（研究者 10-31 的表述）

> 在缺少逐步 ground truth 的情况下，能否把已有的 hint（相当于 DeepSeek 已公开的 audit / pattern card）转化为与视觉推理正确性稳定相关、又不容易被模型钻空子的过程信号？

- 目标**不是**把 hint 直接当 RL 奖励，而是把 hint 转化成**可验证的推理过程信号**。
- **SFT 的定位**：A-SFT 是一个“短 caption、基础行为”的标准语料。它是在多个强模型都答对的轨迹里自然筛出来的，筛选时检查过 caption 里的断言是否有视觉依据。SFT 只教了基本格式和行为；希望通过奖励设计，让 hint 描述的那些能力在 RL 中涌现出来。
- **监督档位**：这个问题介于“只有终答”和“每题一个目标真值”之间；逐步过程标签（PRM 那一档）不在考虑范围内。

| 档位 | 需要什么 | 对应 |
|---|---|---|
| ① 只有终答 | 答案字母 | 现在的 0/1 奖励 |
| ② 每题一个目标真值 | 每题一个或几个归一化框，不是逐步标签 | 导师的“目标逼近 / 探索 + gate” |
| ③ 逐步标签 | 每一步对不对 | PRM 一类，不做 |

## 2. 实测一：4B 在区域层面能把裁图落到目标上

V\* 有真值框，取 E1 中的 112 题，每题 4 次采样，共 448 条轨迹。“命中”的定义：每个真值框都有至少 90% 被某一次裁图包住。

| 条件 | 有裁图的轨迹 | 命中率 | 命中时准确率 | 未命中时准确率 | 最佳 IoU 中位数 | 单次裁图面积 / 整图（中位数） |
|---|---|---|---|---|---|---|
| SFT | 345 | 0.757 | 0.943 | 0.607 | 0.045 | 2.5% |
| 6k×16 GRPO（B4） | 447 | 0.879 | 0.898 | 0.519 | 0.046 | 5.0% |
| GRPO | 447 | 0.841 | 0.899 | 0.549 | 0.036 | 4.4% |
| DAPO | 447 | 0.864 | 0.920 | 0.590 | 0.029 | 4.8% |
| GSPO | 447 | 0.855 | 0.890 | 0.523 | 0.031 | 4.6% |
| GiGPO | 447 | 0.781 | 0.903 | 0.582 | 0.047 | 2.6% |

- 命中与否和准确率有关联（约 0.9 对 0.55）。这是**跨轨迹**的对比；同一题的 8 条轨迹之间能否区分，还没测。
- 裁图远大于目标，IoU 中位数只有 0.03–0.05。所以导师公式里的 IoU 项接近 0，起作用的主要是覆盖项。而覆盖项可以被整图裁剪刷到接近 1（见 BRIDGE §7）。
- DeepSeek 用 4,000 万条 grounding 数据做预训练，目的是装上定位能力。Qwen3-VL 的预训练里本来就有 grounding（会输出 `bbox_2d`；这一点是研究者的记忆，尚未逐条核对原文）。上表说明，**区域层面的指代 4B 是做得到的**。
- 没有测过的：密集计数、多个候选时认对是哪一个实体、空间关系。只有零星样例。

## 3. 实测二：只用终答奖励时，RL 放大了哪些行为

E1 每个条件 2,208 条轨迹，括号内是占全部轮次的比例：

| 行为 | SFT | GRPO / DAPO / GSPO / GiGPO |
|---|---|---|
| fallback 轮 | 278（6.3%） | 738 / 810 / 596 / 1,058（8–16%） |
| 含 fallback 的轨迹 | 171 | 541 / 495 / 416 / 577 |
| 裁图 ≥3 次的轨迹 | 193 | 514 / 599 / 656 / 508 |
| HOLD 轮 | 6（0.1%） | 14 / 21 / 8 / 29 |
| REVISE 轮 | 1 | 5 / 2 / 1 / 6 |
| abstain 轮 | 8 | 6 / 0 / 1 / 5 |
| 写出“已排除区域”的轮 | 9 | 7 / 8 / 4 / 4 |
| CALC 轮 | 63（1.4%） | 58 / 139 / 16 / 70 |
| caption 里出现坐标的轮 | 2 / 4,403 | 15 / 17 / 23 / 17 |

- 在 SFT 里占几个百分点的行为（fallback、多次裁图），RL 之后放大到 2–3 倍。
- 在 SFT 里接近 0 的行为（HOLD、REVISE、abstain、记录已排除区域、caption 里写坐标），RL 之后基本没有长出来。
- hint 希望出现的行为，大多属于后一类。**加了过程奖励之后能不能长出来，目前没有数据**；这正是 A 路线的主要风险。

## 4. 对 primitives 的理解：在我们的协议下能桥接什么

**对应关系**：论文“在 CoT 里写框”，在我们这里对应**会被执行的裁图框**（区域指针）加上 **`[observation_k]` 视图引用**（视图句柄）。论文“用标注校验 primitive”，在我们这里对应“**用真值 bbox 校验裁图动作**”。

| 论文在 CoT 里的行为 | 我们的轨迹 | A 路线下能否桥接 |
|---|---|---|
| 框出区域 | 执行裁图，记录在 `boxes_abs` | 能 |
| 指向某张视图 | `[observation_k]` 引用 | 能 |
| 一次框出全部候选 / 逐个核对 | caption 只允许 1–3 句，写不下候选清单 | 要改协议和 SFT，A 路线不做 |
| 在文字里给实体框（“这个红色物体”是哪一个） | 协议禁止在 caption 里写坐标 | 同上 |
| 有序的点 / 路径 | 没有；RL 题池里 map 类近乎为 0 | 不做 |
| 回溯、排除 | fallback 有；“已排除区域”接近 0 | 有格式位置，但频率很低 |

**Reference Gap 能否转成奖励：只能部分转。**
- **区域层面**（裁图有没有落到目标上）：有真值框就能检查，也就是导师的逼近信号。
- **关系层面**：两个对象都有框时，关系可以直接从坐标算出来。
- **文字里的实体指代**：A 路线下不改格式，只能用两种代理：
  1. **引用代理**：commit 时引用的那张视图有没有包住真值目标。局限是一张视图里有多个候选时分不出来。
  2. **只作评测观察**：导师说过，观测是否属实这类现象是附带效果，不直接优化。

  研究者认为文字实体指代应该做；如果以后要做到实体级，需要补充 SFT 格式，留作 B 路线的储备。

**DeepSeek 的难题**（迷宫、线路追踪）：属于合成任务，题池里没有，4B 也不太可能做。题目不搬过来，但借用其奖励写法：双向距离（同时罚框太大和没框到）、连续性惩罚（防止跳到猜测的终点）、探索完整度（用于“不存在”类题）、过滤大框。

**hint / skill 的识别**：对应论文局限 2（要靠触发词才启用）。标签可以用协议的 `task_hints` 规则从题面自动生成。但规则只看文字，模型学会分类本身没什么价值；关键要看识别之后，后续行为是否跟着变。这和首动作分叉（v53）属于同一类问题。

## 5. A / B 两条路线（已选 A）

| | A：保留 A-SFT，只改 RL（**已选**） | B：重做 SFT，再做 RL（储备） |
|---|---|---|
| 研究问题 | 无逐步真值时，从 hint 和标注构造抗投机的过程信号，作用在会被执行的裁图上 | 冷启动教会结构化行为，RL 再强化 |
| 和 DeepSeek 的区别 | DeepSeek 在一般 VQA 上明确**不监督** RL 中的 primitive；A 恰好监督这一侧 | 结构接近 DeepSeek 的“冷启动 + RL”；在 4B 上容易被看成小规模复现 |
| 已有 baseline | 第 2–4 类全部继续有效 | 都要在新 SFT 上重跑，还要加同一 SFT 的 GRPO 对照 |
| 导师立场 | 符合“不用太去修改 SFT”和“补 bbox 后纳入 RL” | 需要和导师确认 |
| 主要风险 | §3 中接近 0 的行为，RL 可能放大不出来 | 工作量大；caption 变长会增加成本 |

B 只写协议差异草案，不生成数据：caption 允许列出候选清单、记录已排除区域、加入拒答负样本、加入实体级引用。

## 6. 候选信号要过的四关（离线验证，不需要训练）

1. **组内区分度**：同一题的 8 条轨迹里，信号能否区分答对与答错。GRPO 只用组内差异。
2. **依据**：能否把“答对但依据不对”（已有审查病例）和“答对且依据对”分开。
3. **抗投机**：对人为构造的投机轨迹（整图裁剪、网格扫图、反复引用同一视图）不涨分。
4. **成本方向**：不鼓励多裁图。

现成数据：V\* 112 题有真值框，25 个条件都有 E1 轨迹和 `boxes_abs`。题池标注出子集后，再把验证扩展到 OCR 和表格题。

## 7. 把握（研究者要求的评估，讨论稿）

| 步骤 | 把握 | 依据 |
|---|---|---|
| 标注类型方案 | 高 | 主要是机械工作，进度见 §8 |
| 离线验证能否做出来 | 高 | V\* 数据现成；但只覆盖“找物体”这一类 |
| 信号能否过四关 | 中 | 已有跨轨迹关联；组内区分度未测；覆盖项已确认会被整图裁剪刷分，必须先改 |
| RL 超过 DAPO（E1 .6635） | 低到中 | 此前 PO（SP / CA）、v53 都没有超过 DAPO；V\* 命中率已经是 84–88% |
| 论文新颖性 | 中 | 要核对近邻工作（例如用框 IoU 作 RL 奖励的工作），尚未核对 |

**粗算上限（只是算术，不是预测）**：DAPO 在 V\* 上有 61 条未命中轨迹。假设它们全部变成命中，准确率达到命中时的 0.920，大约多答对 20 条，相当于 V\* +4.5 个点、E1 整体约 +0.9 个点。更大的提升空间只能来自 MME-RealWorld（E1 中 339 题）；那部分的命中率要等题池标注后才能测。

## 8. 计划与进度

1. **标注类型**（第一轮完成，2026-11-01）：
   - **元数据**：RL 题池 4,096 题已补齐。`material` 的来源：和 funnel 池匹配 2,203 题，按目录推出 1,248 题，按 uid 推出 351 题；**WorldBench 有 294 题推不出**。
   - **更正**：题池里 `extra_info.question` 字段被截断在 200 字符（1,318 题）。模型实际看到的 prompt 里，4,096 题的选项都是完整的。抽样中受影响的 38 题已按完整题面重新审查。
   - **规则草案 vs 看图**：分层抽 163 题，由 3 个审查 agent 看图核对，一致的只有 **66/163**。三种主要错误：
     - 位置描述（top left、right side、largest）被当成关系或比较，实际大多只需框一个文字或物体；
     - 关键词（cell、column、how many、path）被当成表格或计数；
     - gt 为“不存在 / 以上都不是”时，仍可能有可框的证据，或需要逐个比较候选。
   - **全量分布的分层估计**（每层 7–16 题样本，只是粗估）：

     | 单位 | 估计题数 | 主目标面积 / 整图（审查者粗估的中位数） |
     |---|---:|---:|
     | single_box | 1,782 | 0.003 |
     | keyed_set（表格 / 图表的多角色框） | 1,036 | 0.001 |
     | region_global | 405 | 0.85 |
     | multi_compare | 236 | 0.15 |
     | unanswerable_or_bad | 224 | — |
     | multi_set | 220 | 0.08 |

     | absent | 34 | — |

     可框程度的估计：easy 约 3,344、hard 约 505、no_box 约 246。
   - **题目本身的问题**：163 题中，看图与 gt 不符的有 5 题，看图无法回答的有 6 题。其中 4 题是 nuScenes 单帧图，问自车的转向或车速。题池中提到 ego 的驾驶类题：nuScenes 324 题、Rank2Tell 62 题；其中有多少单帧无法回答，没有逐题看过。
   - **待定**：
     - 逐题的标注单位用什么方式定（正则不可靠）；

2. **真值框标注**：在哪些子集上标、由谁来标（人工还是教师模型）、坐标统一用 [0,1] 归一化，都待研究者授权。
3. **离线验证**：先在 V\* 上过 §6 的四关；题池标注出子集后，扩展到 OCR 和表格题；§3 的行为频率作为基线。
4. **回到 reward shaping 设计**：gate 的触发条件、过程项系数、多框怎么聚合、按步还是只在终点给信号（BRIDGE §7 的四个未定项）。
