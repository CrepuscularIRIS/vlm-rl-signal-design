## 0. 核心直觉：把“探索—观察一致性—终答”串成一条线，并压到最低标注比特

在标准 outcome-only GRPO 下，同一道题的 8 条自然轨迹常出现**全对组（$Y \equiv 1$）或全错组（$Y \equiv 0$）**（每 minibatch 约 45% 轨迹因优势为 0 被跳过），终答奖励无法区分两类本质不同的过程失败：

```
原图信息不够 ──▶ [① 探索取证 B4] ──▶ 局部图回来 ──▶ [② 跨图观察一致性/归属 B1 & 更新 B2] ──▶ [③ 组合计算 B3] ──▶ 终答 Y
```

- **为什么主流 VLM 普遍卡在这两环之间的张力？**
  - `Qwen3-VL` 对每张裁图使用彼此独立的局部 2D mRoPE，`InternVL` 使用 1D 文本 RoPE + 动态 `448×448` 切块，**两者在多张局部裁图之间都没有共享的全局 2D 位置编码**。
  - 因此，“放大细节（裁得够近）”与“保住身份上下文（不把邻近对象的值张冠李戴，如第 15780 题将邻柜 `16` 写给棕框 `17`、第 1077 题跨视图重复计数）”天然存在张力。
- **为什么用“静态特权先验 + 同终奖分层优势”替代在线 Judge？**
  - 在线 VLM-as-Judge（如 OPO 的 ELAA、VERA）成本高、依赖外部裁判且易被刷分；
  - 熵（bbox 熵 / 答案 top-k 熵）只测不确定性，**没有方向感**（模型可以极低熵、极自信地看错邻柜）；
  - 我们改为**在训练前一次性压缩人类视觉直觉为最低比特数的静态特权标签**（训练中只做纯 CPU 几何运算，或只用正在训练的本地模型自己做 Append-Only 1-token 读出），并用**同终奖分层中心化**接入 GRPO。

## 1. 关键机制：全错组与全对组（同终奖组）如何获得有效信号？

> **明确回答：是的，不仅 B4，所有进入同终奖分层接口的信号（B4、B1①、B1②）都会主动为全错组（$Y \equiv 0$）和全对组（$Y \equiv 1$）提供受控的正负信号，从而盘活标准 GRPO 里原本零梯度的 45% 轨迹。**

### 1.1 为什么标准 GRPO 丢掉了全错组？
在标准 outcome-only GRPO 中，组优势 $A_i^{\text{GRPO}}(Y) = \frac{Y_i - \bar{Y}_g}{\text{std}_g(Y) + \epsilon}$。
- 当一道难题的 8 条轨迹**全错（$Y \equiv 0$）**时，哪怕其中 2 条已经准确把关键细节放大了 $2\times$（只是最后一步算错），另外 6 条全裁到了无关背景，8 条的 $A_i^{\text{GRPO}}$ 全部等于 `0`，在 `CAPTION_SKIP_ZERO_ADV=1` 下被直接跳过，**模型永远学不到“那 2 条的找图方向是对的”**。
- 当一道题**全对（$Y \equiv 1$）**时，靠蒙或靠无关裁图碰巧答对的轨迹，与老老实实放大目标并认对对象的轨迹拿到同样的 `0` 优势。

### 1.2 同终奖分层中心化接口（如何安全激活全错/全对组）
设同题组 $g$ 内，具有**相同终答分 $Y_i = y \in \{0, 1\}$**、格式合法且满足适用条件（`m_i = 1`；例如 B4 首裁版要求“均执行了首裁”）的兄弟子集为 $H_{g, y}$。当 $|H_{g, y}| \ge 2$ 时，定义层内中心化过程优势：

$$d_i = S_i - \frac{1}{|H_{g, y}|} \sum_{j \in H_{g, y}} S_j, \qquad \tilde{A}_{i, u} = A_i^{\text{GRPO}}(Y) + \lambda \cdot d_i \cdot w_{i, u}$$

**在三种组型下的精确行为**：
1. **全错组（$Y \equiv 0$）**：$A_i^{\text{GRPO}}(Y) = 0$，此时 $\tilde{A}_{i, u} = \lambda d_i w_{i, u}$。
   - **以 B4 为例**：8 条全错轨迹中，2 条首裁命中关键点 $p_q$ 且放大 $\ge 1.5\times$（$S_i = 1$），6 条没命中（$S_i = 0$），则 $\bar{S}_H = 0.25$；命中者获得 $+\mathbf{0.75}\lambda$ 的正优势，未命中者获得 $-\mathbf{0.25}\lambda$ 的负优势。这批原本被跳过的全错组**重新进入 Actor 更新**，把策略从“盲扫全错”推向“先看准关键细节”，随后才更容易出现混合组并被终答奖励接管。
   - **同样适用于 B1①**：8 条全错轨迹里，如果 3 条在裁图后旁路二选一认对了“棕框是 17 而非 16”（错在末端算术），5 条认成了 16，认对对象的 3 条获得正优势。
2. **全对组（$Y \equiv 1$）**：同样 $A_i^{\text{GRPO}}(Y) = 0$，但真正看清目标/认对对象的正确轨迹压过“碰巧蒙对”的正确轨迹。
3. **混合组（有对有错）**：正确轨迹只在 $H_{g,1}$ 内部互比，错误轨迹只在 $H_{g,0}$ 内部互比，$\sum_{i \in H_{g,y}} d_i = 0$，**彻底杜绝“高过程分错题反超对题（Reward Inversion）”**；同时不除以 $\text{std}(S)$，**彻底杜绝微小过程差异在全同终奖组被 z-score 放大成 $\pm 1$ 的方差爆炸**。
4. **严格退化与成本记账**：$\lambda = 0$ 时逐位退化为标准 GRPO；全错/全对组重入 Actor 后，训练监控须单独统计 re-entering 组数与 `zero_adv_skipped` 变化。

> **关于全错组的一个风险提示（Audit 必查）**：如果全错组里“命中 $p_q$ 的轨迹”是因为模型死循环/胡乱回答而碰巧框中，持续给正优势可能放大坏的作答习惯；因此**必须保留 `CAPTION_MASK_TRUNCATED=1` 与 `invalid` 排除**（仅合法完成作答的轨迹进入 $H_{g,0}$），且 $\lambda$ 保持小幅有界（如 $0.1 \sim 0.2$），必要时在训练后半程对比“全错+全对都开”与“仅全错开”或“局部 span 路由（只给 `<grounding>` 动作加正优势，不给错答 `<answer>` 加正优势）”。

## 2. B1 到 B4 分别对应什么问题？极简压缩方案全解

下面逐一展开 **B4、B1、B2、B3** 分别解决什么失败模式、人类直觉如何压到最低比特、具体公式是什么，以及各自的正面收益与反例边界。

### 2.1 B4：取证探索与放大尺度（“信息不够时，第一眼往哪里看、放大够不够？”）

- **对应的核心问题**：
  原图经缩放后关键细节像素不足（resolution bottleneck），模型需要主动裁图；但标准 GRPO 无法在同终奖轨迹里区分“第一眼就找准位置并有效放大”与“盲扫整图/框得太大没放大/裁 5 次碰运气”。
- **为什么只有 B4 天然满足“一次标注、零额外前向、每条裁图可微秒级重算”**：
  因为 B4 测的是物理空间必要条件，静态坐标 $p_q=(x,y)$ 绑定在（原图+题目）上，与策略文本完全解耦，训练期纯 CPU 计算，零正则失败、零 GPU 耗时。
- **极简压缩标注**：
  - **单点版（B4-pt）**：给标注者看原图、题目与标准答案，只问一句：*“如果只能让别人放大一处来核对答案，你会点哪里？”*（全图比较/分散计数题允许选“无单一位置”，记 `m=0`）。
  - **多点扩展版（B4-set，针对 ZwZ2 多彩框题）**：允许点 2–3 个必要点 $P_q$，避免多目标题（如同时看红框和绿框）误罚先看合法目标 B 的轨迹。
- **打分公式**：
  - 首裁单点版（防 5 裁抽奖）：
    $$S_i^{\text{B4-pt}} = \mathbf{1}[p_q \in C_{i,1}] \cdot \mathbf{1}[s_{i,1} / s_0 \ge 1.5]$$
    其中 $C_{i,1}$ 为首裁在原图坐标系下的实际执行框，$s_{i,1}/s_0$ 为实际呈现倍率（Qwen 用 `present.py`，InternVL 用 `ivl_adapter.py` 动态 tile 画布倍率，均为确定性纯 CPU 公式）。
  - 多点集齐版：
    $$S_i^{\text{B4-set}} = \frac{1}{|P_q|} \sum_{p \in P_q} \big(\max_{v \in V_i} z(v,p) - z(v_0, p)\big), \quad z(v,p) = \mathbf{1}[p \in v]\mathbf{1}[s(v)/s_0 \ge 1.5]$$
- **边界与局限**：只管“看见、放大”，不管“放大后把邻柜的值归错对象（B1）”。

### 2.2 B1：对象-值归属与跨图观察一致性（“放大细节后，有没有把值归给正确的对象？”）

- **对应的核心问题**：
  像素已经进入上下文，模型也读出了一个清晰的值，但**跨视图身份对齐失败**——把邻近对象的读数张冠李戴（如第 15780 题宽窗覆盖了棕框 17 号柜台，末裁落到邻柜 16 并写成棕框读数）。在冻结视觉塔下，**这是“探索之后仍答错”的最重要候选根因**。
- **为什么 B1 不能纯靠单点几何，必须付一点额外开销**：
  B1 发生在认知层。为避免旧 L2 自由文本正则召回率过低（5,476 对仅 41 对非零），我们将 B1 压缩为三种极轻形态（**训练期均为 0 外部 API、0 外部 Judge**）：

1. **B1① 对象二选一（首选认知切入点：1 次 Append-Only 请求，读 1 个 token）**：
   - **离线静态标注**：每题只准备一条极简二选一 `(u, e+, e-)`（如“棕框柜台号是 A. 17 还是 B. 16？”）。旧 MME L2 已有 **86 题**现成带目标值与真实邻近干扰项 `negatives`；其余可离线辅助预标 + 人工抽检冻结为 JSON。
   - **在线计算（零外部 Judge，命中 Prefix Cache）**：在 rollout 历史末尾追加约 20 token 的旁路提问，**只用本地被训策略自己（vLLM `theta_old`）**读下一个输出位置对 `" A"` 和 `" B"` 的 logit（Qwen3-VL 已核实 `Choice:` 后 `" A"`/`" B"` 分别为单 token `362`、`425`，避开 `17` 占 3 个 token 的多 token 偏差）：
     $$S_i^{\text{B1-1}} = \frac{e^{z_{\text{正确候选}}}}{e^{z_{\text{正确候选}}} + e^{z_{\text{干扰候选}}}}$$
   - **核心工程优势**：因为是**末尾追加（Append-Only）**，整段原图+裁图+历史文本的 KV Cache 在 vLLM（`enable_prefix_caching=true`）中 **100% 命中**，实际新增算力极低，且**跨 Qwen / InternVL 100% 通用**。
   - **防作弊与必过证伪（对象翻转检验）**：同题兄弟用相同选项顺序，跨题平衡 A/B，抽检翻转防字母偏置；在审计中固定图栈和 `16/17`，**只把问句从“棕框几号”换成“邻柜几号”**，只有偏好随之翻转才说明测到的是真实绑定而非单纯“图里有 17”。

2. **B1② 只标一个正确值（次选 / 对照：1 次短串 Teacher-Forcing）**：
   - **离线静态标注**：只标 `(u, e+)`（无需找邻近干扰项，直接复用已有键值表）。
   - **在线计算**：同样 Append-Only 挂在历史末尾，对短串 `e+` 做 1 次 teacher-forcing 算对数概率（命中 Prefix Cache）。适合没有明显邻近干扰项的题；审计时需排除“历史 `<think>` 已写出 `e+` 退化为语言复述”的情况。

3. **B1-Geo 几何近似版（0 GPU 前向，多点 1 下鼠标）**：
   - 点 2 个点：`p_K ↔ p_D`（身份线索点 + 读数点，算同窗 $J(V)=\max_v z(v,p_K)z(v,p_D)$ vs 分窗对照 $I(V)$），或 `p_+ / p_-`（正点 + 易混邻近干扰点，惩罚末裁只放大 $p_-$ 却切掉 $p_+$）。纯 CPU 计算，可作为 B1① 的零前向几何对照。

### 2.3 B2：证据更新（“拿到高清新视图后，是有效纠错，还是见图乱改口？”）

- **对应的核心问题**：
  区分“真正由新增清晰像素带来的有效信念更新”与“看到任何新图（哪怕毫无新增信息）就胡乱改口或盲目涨自信”。
- **极简压缩方案（0 新增人工标注）**：
  - 复用原题选择题金标 $y^*$（覆盖 85% RL 池），对比真实高清裁图 $V_i^{\text{real}}$ 与同位置等尺寸低清重放控制视图 $V_i^{\text{ctrl}}$ 下的 1-token 金标读出差（`stop_baseline.py::combine`）。
- **定位降级原因（工程算力账本）**：
  - 虽然 0 离线标注，但**替换中间图像会导致 vLLM Prefix Cache 在图像处断裂**，触发整段视觉与后续文本重 prefill（13K 池抽 25% 即 52,000 次视觉重 prefill），训练期吞吐开销远高于 Append-Only 的 B1①。因此 **B2 保留为小样本离线诊断和零标注参照基线**，不优先直接塞进 51 步全量训练。

---

### 2.4 B3：决策操作数与跨视图去重（“单个对象读对了，最后算术/计数有没有用错或数重？”）

- **对应的核心问题**：
  单图读数和绑定正确，但跨视图重复计入同一对象（如第 1077 题把同一栋楼数了两次得 6 栋而非 5 栋）或末端加法凑错操作数。
- **极简压缩方案**：
  - 离线仅针对计数/算术子集标一个操作数多重集（如 `{14, 15, 17}`），在线用纯 CPU 正则检查 `CALC:` 行或自然算式（0 前向）。
- **定位降级原因（覆盖率实测）**：
  - 在 120 条自然首裁续写中实测：`CALC:` 仅出现 **0/120（SFT）与 2/120（历史 GRPO）**，放宽到普通整数加法也仅 **6/120 与 8/120**。覆盖率过低，暂不作为全池主奖励，保留为子集离线诊断。

## 3. 拟向导师汇报的“额外离线标注行为”清单与边界

所有拟议的额外标注均遵循三条硬纪律：**① 只在训练前针对静态题池（原图+题目+金标）一次性完成，不碰任何 RL rollout 轨迹；② 训练期 0 外部 API、0 外部 VLM-as-Judge；③ 先在 60–80 个独立原图家族上跑完离线 Audit 验证区分力，过关后再讨论是否扩量到训练集。**

| 拟议标注行为 | 标注员/离线预标具体做什么 | 每题成本 | 现成可零成本复用的资产 | 训练期额外算力 | 对应要解决的问题 |
|---|---|---|---|---|---|
| **标注行为 A：关键证据点（单点 $p_q$ / 双点 `p_+, p_-`）** | 看原图+题+金标，在图上点 1 下“核对答案最该放大的点”（多目标可点 2–3 下，全图题标“无单一位置”）；有邻近干扰时多点 1 下干扰对象 $p_-$ 或身份锚点 $p_K$。 | 极低（点 1–2 下鼠标，约 5–10 秒/题；可用强 VLM 离线预标 + 人工抽检） | ZwZ2 已有 5,528 题的多彩框供点选；MME 旧 L1 已有 **242 题**现成 `header (K)` + `cell (D)` + `negatives` 坐标框。 | **0**（纯 CPU 几何） | **B4（信息不够去探索 & 有效放大）**，兼顾全错组激活与 B1 几何防错瞄 |
| **标注行为 B：对象二选一短题 `(u, e+, e-)`** | 只写 3 个短词：局部对象问句 `u`、正确值 `e+`、同图真实易混干扰值 `e-`（如“棕框柜台号”、`17`、`16`）；无明显干扰项时只写 `(u, e+)`（B1②）。 | 低～中（人工约 15–25 秒/题；可离线强 VLM 预生成 + 规则/人工抽检） | MME 旧 L2 已有 **86 题**现成 `target + negative` 文本与绑定字段，可直接零标注先跑先导 Audit。 | **极低**（本地策略 Append-Only 读 1 token，命中 vLLM Prefix Cache） | **B1（跨图观察一致性与对象-值归属）**，在全对/全错组拉开认对与错绑轨迹 |

## 5. 下一步离线 Audit 计划（向导师汇报后的第一个动作，0 训练）

不预设任何方案必然有效，先在**同一批带完整 `boxes_abs` 和 `turns` 的自然 8-rollout 兄弟轨迹**上做一次小规模离线 Audit（抽 **60–80 个独立原图家族**：30–40 道现成 MME 旧 L1/L2 题 + 30–40 个 ZwZ2 互补家族，冻结 4K SFT 推理采样）：

1. **测全错组与全对组的真实区分覆盖率**：分别报 `B4-pt`、`B1-Geo`、`B1①`、`B1②` 在全错组（$Y \equiv 0$）、全对组（$Y \equiv 1$）、混合组中实际拉开同终奖兄弟的比例与独立家族数。
2. **测方向正确率（正面 vs 反例比）**：
   - `B4-pt`：盲核实际回执是否确实更利于答题，并与**同分布随机点**对比；
