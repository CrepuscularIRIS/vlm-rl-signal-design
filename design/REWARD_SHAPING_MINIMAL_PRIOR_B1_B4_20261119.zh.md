# 面向主动视觉观测的极简可验证证据塑形主线方案（B4 + B1 统一框架）

> **更新日期**：2026-11-20（确立对标并极简化 CAVE/OPO 的普遍问题主线、单一证据状态 $\Phi(h_t)$ 统一公式、跨 GRPO/DAPO 通用训练机制及配套 Testbed 草案）
> **硬性边界**：
> 1. **底座与环境约束**：小模型起步（`Qwen3-VL-4B-Instruct`，机制 100% 兼容 `InternVL3.5`），冻结视觉塔与投影层（`freeze_vision_tower=true`、`freeze_multi_modal_projector=true`），单静态原图 `B5` 预算（$\le 5$ 次真实裁图，允许 0 裁直答），主奖励采用严格终答规则 `fv1_rule_v2`。
> 2. **零协议侵入与零在线裁判**：**完全不修改 `Caption v5.1` 协议**；RL 训练期 **0 外部 API、0 在线 LLM/VLM-as-Judge**。
> 3. **优化器无关定位**：本方案是一套作用于整个 RL 训练过程的**过程监督与信用分配机制插件**——搭在 `GRPO` 上即与同起点标准 `GRPO` 公平对比，搭在 `DAPO` 上即与同起点标准 `DAPO` 公平对比，统一用下游准确率与成本（首裁/后续裁图数、总处理 token）的 Trade-off 曲线裁决。

## 0. 问题定调：不赌小概率假设，瞄准像 CAVE 一样全池普遍存在的真问题

### 0.1 选题准则：稳妥、普遍、顺应常识但直指现有解法之“重”
- **不挑战公认有效的核心动作，不押注罕见 corner case**：对于 4B 小模型 + 冻结视觉塔，主动放大（Zoom/Crop）本身是克服分辨率瓶颈的必要正确操作，不应反向质疑“放大”本身；同时，审计表明显式算式错误（B3，自然出现率 $<7\%$）和中间低清重放（B2，打断缓存）覆盖面较窄，而若把 B1 窄化为“两个对象都看清却纯粹把名字填反”，在全池自然轨迹中也存在沦为局部小概率事件的风险。
- **真正贯穿 13K 全池（ZwZ2 9,100 + MME 2,000 + VP 1,900）的普遍主矛盾**：
  与 CAVE（*Fragmented & Confusable Visual Evidence*）和 OPO（*Where to Look under Sparse Rewards*）所观察到的现象一致，在单图多步主动观测中，模型能否真正靠视觉证据做对题，普遍卡在以下因果链的前两环：

```text
原图细节模糊或跨区分散 ──▶ [① 取证与恢复 B4：把所需的 1～k 处证据放大到可读尺度，偏航能回退，够看即停]
                       ──▶ [② 观察一致性 B1：从局部视图中提取属于目标对象的准确视觉事实，排除邻近干扰与选项蒙猜]
                       ──▶ 终答 Y ∈ {0, 1}
```

**为什么稀疏终答 $Y \in \{0, 1\}$ 在整个训练池上普遍限制学习？**
1. **前驱取证与偏航恢复被零奖抹杀**：碎片化证据题（如跨多处彩框核对、跨表头与数据格比对）前几步找对局部区域或从错框恢复（Recovery）时，终答尚未变对；一旦末端推理出错或漏看一处，整轨 $Y=0$（云端冻结基线第 1–8 步中 **616/2,048 = 30.08%** 的组为全对或全错零优势组），正确的探索与恢复动作拿不到正向梯度。
2. **选项蒙猜与无效重裁混同获奖**：13K 训练池中 **85% 为四选一选择题**（ZwZ2 + MME），裁偏了靠选项先验仍有 $\ge 25\%$ 概率蒙对 `Y=1`；证据早已看清后继续盲目重裁 2～3 次（实测证据充分前缀下标准 GRPO 自然停止率仅 `20/64`，多耗约 3 倍处理 token），也与干净取证的轨迹获得完全相同的终答分。

### 0.2 现有代表机制为什么不足（臃肿或失真）？

| 代表路线 | 解决了什么 | 核心不足（本方案要简化的地方） |
|---|---|---|
| **OPO** | 用局部观测充分性替代裁图动作上的全局终答优势 | ① 在线调用冻结大模型 `Qwen3-VL-Max` 逐图打分（算力重、依赖外部 Judge）；② 用无语义方向的 bbox 坐标 token 熵触发分叉；③ 单张局部裁图脱离全局上下文时难以核实多对象归属。 |
| **CAVE** | 对碎片化视觉推理引入“信念更新 + 证据获取 + 聚焦尺度”三项过程信号 | ① **前向开销重**：离线构造 $K$ 条完整证据长句，训练时逐步做 $(T+1)(K+1)$ 次整句 teacher-forcing；② **尺度估计间接**：用答案 top-500 词表条件熵估算目标裁图面积，但词表熵与图像物理字号无可靠单调关系；③ **整句与选项噪声**：长句似然混入语法模板词，终答似然在多选题上受选项偏置影响。 |
| **朴素紧致 bbox IoU** | 纯几何计算目标逼近与探索面积 | ① 紧贴局部数字描框会惩罚保留表头/框标身份的合理宽窗（IoU 低），大框刷覆盖率又在冻结视觉塔下看不清像素；② 纯几何框重叠无法检验模型是否真正读出了目标对象的值。 |

## 1. 本质推演：有没有比「B4 + B1」更优雅的做法？—— 单一可验证证据状态 $\Phi(h_t)$

从第一性原理审视“零在线 Judge + 冻结视觉塔 + 不改协议”下的设计空间：
- **能不能完全零离线标注（纯靠策略自身答案概率/熵，如 `pbrs_qs` / `CA-RVT`）？** 不够稳：在 85% 四选一题池上，模型自身选项概率受先验偏置严重污染（历史实测单步强制作答概率差折半信度仅 `0.51`），无法区分“真看清目标”与“语言盲猜涨自信”。
- **能不能只留 B1 砍掉 B4，或只留 B4 砍掉 B1？**
  - 只留 B4（纯几何+尺度）：0 算力、前驱探索方向最稳，但区分不了“框住了区域却切丢表头/看串邻框”；
  - 只留 B1（单 token 事实探针）：在结果上能兜底，但多区域题只看清第一处时探针尚未跳变，缺少零成本的逐步探索引导。
- **最优雅的统一形态（不是把 B4 和 B1 拼成两个独立补丁，而是合成为同一个状态函数！）**：
  将每道题的离线特权先验统一定义为 **1 张极简「可验证视觉证据卡」**，使任意交互历史 $h_t$ 映射为**单一有界证据状态势能 $\Phi(h_t) \in [0, 1]$**：

$$\Phi(h_t) = \underbrace{C^{\text{B4}}(h_t)}_{\text{可读尺度空间获取率 (纯 CPU)}} \times \Big((1 - \alpha m^{\text{B1}}) + \alpha m^{\text{B1}} \cdot \underbrace{B^{\text{B1}}(h_t)}_{\text{去偏目标事实核验度 (1-token)}}\Big)$$

（其中无 B1 探针题 $m^{\text{B1}}=0$ 时自动退化为纯 $\Phi^{\text{B4}}$；消融实验令 $\alpha=0$ 即纯 B4，令 $C^{\text{B4}}\equiv 1$ 即纯 B1，**零模块拼凑感**！）

这一条公式同时自然覆盖四个目标行为：
1. **探索（Exploration）**：未将目标证据放大到可读倍率时 $C^{\text{B4}}=0 \implies \Phi=0$，首次有效放大即获得正向跃升；
2. **偏航恢复（Recovery）**：第 1 步裁偏（$\Delta\Phi_1 = 0$），第 2 步回原图补裁命中（$\Delta\Phi_2 > 0$），正信号精准归属给恢复动作；
3. **观察一致性（Observation Consistency）**：若裁图虽擦边命中位置但切丢表头或认成邻框干扰值，则 $B^{\text{B1}}$ 低，$\Phi$ 无法拿满，倒逼策略保留身份上下文并认准目标；
4. **够看即停（Stopping）**：原图已可读题（`0_orig_ok`）初始即视为证据完备，或中途一旦 $\Phi(h_t)$ 饱和，后续重复重裁同一区域的边际增量 $\Delta\Phi = 0$。

## 2. 离线极简标注规格（比 CAVE / OPO 轻一个数量级，且保证 Signal $\gg$ Noise）

所有标注在 RL 训练前针对静态 `(原图, 原题, 金标)` **离线一次性生成并冻结**，绝不接触任何 RL rollout：

### 2.1 字段一：B4 互补证据区域集（替代 CAVE 词表熵面积与朴素紧框）
吸取 72 题双模型先导预标教训（纯 4×4 单格会导致多区域题被迫弃权为 `NONE`，且 `10/12` 分歧来自网格线压线相邻格），每题离线标定 `(mode, regions)`：
- **`mode ∈ {0_orig_ok, 1_single, k_multi, abstain}`**：
  - `0_orig_ok`：原图在标准输入分辨率下已足够清晰可答（保护 0 裁直答，多裁无增量）；
  - `1_single` / `k_multi`（$k \in \{2, 3\}$）：给出 1 个或 2～3 个**相互补充且均需核实**的目标证据锚点 $(x_m, y_m)$（ZwZ2 可直接利用检测彩框 + 题干目标半自动提取；MME/VP 用强 VLM 预标）。等价重复线索记 `multi_any`（命中其一即满），全局散点题诚实记 `abstain`（回退纯终答奖）。
- **零 GPU 开销的可读命中判据 $z(v, p_m)$**：
  执行框 $v$ 必须沿 `source` 链映射回原图坐标系，同时满足 **① 带内边距包含锚点 $p_m$**（消除网格边界跳变，保留紧邻表头/框标身份）与 **② 确定性渲染线性放大倍率门控** $\tau_{\min} \le s(v)/s(v_0) \le \tau_{\max}$ 且面积 $a(v) \le a_{\max}$（`Qwen3-VL` 用 `present.py`，`InternVL` 用 `ivl_adapter.py` 动态 tile 公式，彻底替代 CAVE 的 top-500 熵猜尺度）：
  $$C^{\text{B4}}(h_t) = \frac{1}{K} \sum_{m=1}^{K} \max_{v \in V_{\le t}} z(v, p_m) \in [0, 1]$$

### 2.2 字段二：B1「离线信息差过滤」的二选一原子事实探针（替代 CAVE 多长句 Teacher-Forcing）
为使 B1 摆脱“罕见双柜台互换”的窄覆盖，同时杜绝多选题语言先验噪声，将其标准化为普遍适用的原子探针 `(u, e+, e-)`：
1. **候选构造**：针对需要局部取证的题，离线提炼 **1 个回答本题最核心的底层视觉事实问句 `u` + 正确读数 `e+` + 高混淆竞争读数 `e-`**（优先取同图邻框/邻行/邻船真实值；单小目标题取同量纲视觉易混竞争值，剥离原题四选一推理）。
2. **核心去噪机制——离线视觉信息差过滤门（Information-Gap Filter，必过！）**：
   标签入库前，用冻结基座分别在**「仅给缩略原图 $v_0$」**与**「给离线清晰目标裁图 $v^*$」**下测一次单 token `A/B` 概率（并做 `A/B` 顺序对调平均以消除位置偏置）：
   - **准入条件**：仅保留 $P(\text{正确} \mid v_0) \le p_{\text{low}}$（只看缩略原图答不出或偏向干扰项）**且** $P(\text{正确} \mid v_0, v^*) \ge p_{\text{high}}$（看清目标区域后高置信认对）的探针记 `m_B1 = 1`；有双对象真值的子集同步做“换问邻居对象答案翻转”抽检。
   - **效果**：自动滤除一切靠常识就能猜对的伪标签，保证 `m_B1 = 1` 的每一道题 100% 测的都是**真视觉取证 + 真目标绑定**。
3. **训练期超轻计算**：仅在需要区分的轨迹前缀副本末尾 Append-Only 追加约 20 token 的 `Question: <u>\nA. <e+>\nB. <e->\nChoice:`，用本地 `theta_old` 读取 `" A"` / `" B"` 单 token logit 差 $B^{\text{B1}} = \sigma(z_+ - z_-)$。100% 命中 vLLM Prefix Cache，读完即丢，**绝不写回原轨迹**。

## 3. 作用于全训练过程的 Reward Shaping 与信用分配主线（兼容 GRPO 与 DAPO）

围绕单一状态 $\Phi(h_t)$，训练期同时在**「轨迹间（组内排序与零优势组激活）」**和**「轨迹内（步级工具动作信用路由）」**两个层面协同提供更干净的梯度信号，且对底层优化器透明：

### 3.1 轨迹间：同终奖分层过程塑形（主奖励绝对优先 + 盘活同分轨迹）
在同题组 $g$（$G=8$ 条 rollout）内，按严格终答 $Y_i \in \{0, 1\}$ 划分为正确层 $H_{g,1}$ 与错误层 $H_{g,0}$（仅纳入非截断、格式合法的可评分轨迹）。以轨迹末态有效证据分（对 $Y_i=1$ 层可减去温和冗余重裁折减 $-\rho N_i^{\text{red}}$，其中 $N_i^{\text{red}} = \sum_{t} \mathbf{1}[\Delta\Phi_{i,t} \le 0]$ 为零增益冗余裁图数）作为过程质量 $S_i$，做层内中心化：

$$d_i = S_i - \frac{1}{|H_{g, y}|} \sum_{j \in H_{g, y}} S_j$$

- **搭在 GRPO 上（超越标准 GRPO）**：
  - 在标准 GRPO 原本丢弃的约 **28%～30% 全对/全错组**（云端冻结基线实测 `575/2,048` 组含 $\ge 2$ 条可比有效裁图）中，$A_i^{\text{GRPO}}(Y)=0$，分层项 $\lambda d_i$ 直接把这批组盘活——**全错组里找对证据/成功恢复的轨迹获正梯度，全对组里真看清且不瞎重裁的轨迹压过 25% 蒙对与 5 连裁刷步数轨迹**；
  - 在混合组中，限制小系数 $\lambda$ 使组内正确轨总优势始终高于错误轨（零主次倒置）。
- **搭在 DAPO 上（超越标准 DAPO）**：
  - 保留 DAPO 原生 clip-higher 与动态采样优势；在其保留的混合组内，同样存在大量同为 $Y=1$（猜对 vs 真看清）与同为 $Y=0$（全盲扫 vs 已集齐证据仅末步算错）的同层粗糙广播，直接叠加同一套分层与步级信号即可提纯梯度；同时可作为可选扩展放行“全错但组内 $\text{Var}(S_i) > \epsilon$”的高信息难题组，缓解 DAPO 偏向中等难度题的分布漂移。

### 3.2 轨迹内：沿步级边际证据增量 $\Delta\Phi_{i,t}$ 的动作局部路由（探索 + 恢复 + 停止合一）
定义第 $t$ 次裁图回合的边际证据进展为望远镜势差：
$$\Delta\Phi_{i,t} = \Phi(h_{i,t}) - \Phi(h_{i,t-1})$$
将该过程信用精准路由到触发对应观测的 `<grounding>...</grounding>` 动作区间（注意在 `seq` 损失归约下做动作区间长度归一化，并与整轨广播对照）：
- **偏航→恢复**：Step 1 裁偏 $\Delta\Phi_{i,1}=0$，Step 2 回原图找准 $\Delta\Phi_{i,2}>0$ $\implies$ Step 2 独享正向动作信用；
- **看够→停止**：证据收齐后继续原地重裁 $\Delta\Phi_{i,t}=0$（且在 $Y=1$ 层计入冗余步折减）$\implies$ 自动抑制无收益过裁；
- **直答保护**：在 `0_orig_ok` 题上，合法 0 裁直答不产生冗余裁图惩罚，与无需工具的基线自然对齐。

## 4. 配套受控诊断 Testbed 构想（与训练完全隔离的独立贡献）

呼应导师“围绕期望模型具备的行为，构建一套**新的、与 SFT/RL 训练零重叠的数据与直接行为指标**作为加分项 Testbed”的建议，无需大拼盘，紧扣本方案的同一条主线（探索、恢复、观察一致性、够看即停）构建 **`300～500` 题规模的受控主动观测诊断床**（原图家族与 SFT 及 `pool13k` 严格哈希去重）：

| Testbed 诊断切面 | 受控构造方式（零外部 Judge，100% 程序可判） | 直接行为测量指标（超越单一总分） |
|---|---|---|
| **1. 分级观测需求与够看即停**<br>*(Adaptive Acquisition & Stopping)* | 选取高分辨率自然场景、密集报表与示意图，构建三档题目：**`0-Need`（原图直答可解）**、**`1-Need`（单处微细节）**、**`2-Need`（跨远距双碎片整合，对标 CAVE 真实图版）** | ① `0-Need` 自主直答率；② `2-Need` 双证据集齐率；③ **证据集齐后冗余超裁率（Post-Sufficiency Over-Cropping）**；④ 准确率–总处理 Token 曲线 |
| **2. 受控偏航自主恢复**<br>*(Off-Target Backtracking & Recovery)* | 除自由多轮评测外，设**受控首裁偏航协议**：固定注入 1 张落在邻近无关区或仅截到半截线索的真实首裁回执，给相同剩余预算自然续写 | ① 第 2 轮回原图换区率（Backtrack Rate）；② 偏航后目标补齐率；③ 偏航后严格终答恢复率（Recovery Acc） |
| **3. 同图双目标对偶防错绑**<br>*(Paired Dual-Target Binding)* | 每张高混淆原图配**一对同图异问 `(q_A, q_B)`**（如同一报表相邻行列、同一场景相邻标牌/编号），且两题真值互为干扰项 | ① **双题成对同时答对率（Pairwise Flip Acc）**；② **张冠李戴互换率（Target-Swap Error Rate）**（彻底排除靠猜或只认单处显著物的捷径） |

## 5. 执行推进清单（稳步落地）
