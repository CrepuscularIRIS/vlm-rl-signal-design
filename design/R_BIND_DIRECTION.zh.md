## 奖励设计（草案，信用分配位置，探索中立）

```
R = V·(Y + λ·m·Φ_bind)          λ 待冻结（沿 G1 流程先跑离线准入）
Φ_bind 框级粒度（非绑定级全有全无）：
  Φ_see  = 被裁出（单次裁图 ≥90% 框面积）的 support/clue 框比例
           —— 框级计分与裁图次数无关：一次大裁覆盖多框 == 多次小裁（探索中立）
  Φ_dir  = relation 子集（computable_from_boxes）：subject/reference 两框均裁出且
           commit 方向陈述与框几何一致（right of/below 等由坐标直接判定）
  陈述端（值+绑定端文本检查）后置——G1 教训：先验证"看见可被塑造"
m_q = 1 当题有 L1/L2/LC 任一框标注且无分歧标记（disagree 类不进）
```

## 预注册风险与反例（沿 R_READ_FREEZE 流程，训练前必过）

1. **框级 Φ_see 与裁图数正相关风险**：预注册探针成对反例（see 高答错 / see 低答对，人工核 ≥20 对）；若 Φ_see↑ 主要由裁图数驱动 → 加"每框唯一计分、超额裁图不加分"已内置，需复验
2. **方向陈述可从问题文本抄**（"What is to the left of X"）：Φ_dir 的方向词来自题面则不可回填防线弱化 → 反例组：问题文本含方向词的 relation 题单独统计
3. **大裁图刷 Φ_see**：一次全图裁剪覆盖所有框 → 框 ≥90% 覆盖即真看见？——需反例：全图裁（无放大）时模型仍读不出（Probe A 8%）说明覆盖≠可读；预注册：Φ_see 得分的框要求裁图短边 ≥ 该框短边 ×2（放大约束）或分箱报告
4. 离线准入：评分器反例 ≥14 组；实数据冒烟双路径零偏差；无任务信号组 Φ_bind 方差 ≥10%；step1 实值对齐探针
